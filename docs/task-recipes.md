# AI 评论与封面配方

配方库支持图片提示词、AI 评论和图片封面三类用途。图片提示词保留词条、选项和正负提示组合；后两类共用配方身份、修订和生命周期，使用单独的指令正文。封面配方可保存最多八张参考图，评论配方只接收文字指令。

## 使用与编辑

- 配方库中新建时选择用途，填写名称和指令。已有配方可以保存新修订、另存带来源的个人配方、查看旧修订，以及归档／恢复；删除沿配方列表已有动作。
- 扩展页的 Prompt 设置集中选择默认评论配方、默认封面配方，并可打开共用配方编辑器。文章和帖子不新增配方按钮；原有评论和封面动作读取默认配方。未配置或停用扩展时沿原内置方法执行。
- 指令在配方页或扩展设置打开的同一编辑器中修改。另存只保留方法及明确选入的参考，文章正文仍是任务材料；新建和另存不会自动更换默认选择。评论与封面方法不会进入图片提示词组合的选择器。
- 默认选择保存配方身份，未来任务读取其当前已保存修订，开始后固定版本。编辑器保存带当前修订校验，冲突保留输入；离开有修改的任务配方时提供保留或放弃动作。默认配方归档或删除后提示检查 Prompt 设置，不静默替换方法。

## 执行与依据

AI 评论沿文章检查流程运行。配方改变检查重点，不改变返回结构、锚点校验、技术文本保护或正文写入权限。开始时核对配方身份、修订与用途，保存请求、方法来源及当时构造的提示；文章后来变化时，仍沿已有检查结果恢复流程处理。AI 中心可查看该次配方指令，列表不携带完整文章请求。

封面配方结合标题、正文语境和所选画幅生成图片制作输入，配方参考先于自动带入的来源图片，共用已有参考容量。创建工作面时保存方法修订与展开输入；新建同一封面的另一个方案沿用原方法修订。工作面中的“配方指令”展示起步依据，随后手动编辑的提示和实际生成参数由图片输入版本继续保存，起步快照不冒称后续每次模型请求。取消、图片候选、目标核对和采用沿原封面流程。

## 保存与兼容

应用与简体中文语言包版本为 `0.5.10`。数据库修订 `11` 通过新增迁移为配方修订添加 `method_json`，为文章检查添加 `input_json`，为封面制作添加 `recipe_input_json`。已发布的基线和修订 1–10 保持不变；旧记录为空时仍按原行为读取。新方法类型不改写旧图片配方，也不通过模板获得工具或文件权限。

内置 Prompt 扩展标识为 `com.aiy.prompt-recipes`，初始版本为 `0.1.0`，不声明模型、文件或网络权限。默认选择以稳定配方 ID 保存在当前空间既有 `app_meta` 的 `prompt_recipe_defaults_v1` 项中；仅有两个任务槽位，无新增迁移。窄 IPC 校验任务、空间、配方用途与可用状态。沿已有数据库方式执行有界的单行设置读写，不扫描文件或增加启动读取。

任务用途和来源身份使用稳定值；控件、状态及错误提示通过既有语言资源提供。用户的指令正文保持其内容语言。内容包分发、开放插件贡献点、任意参数模板与自动多步工作流未包含在本次接入中。
