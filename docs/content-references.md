# 引用定位与编辑边界

固定引用保存选定来源、范围、修订和必要媒体；引用框不是来源文档的第二个编辑器。调整框高、内部滚动和折叠不改变引用范围，也不改写来源。

## 当前操作

- 原节点菜单：“复制引用”默认取此项；相邻的“查看使用处”列出当前已保存图文与大纲中的实际采用位置。未插入的捕获、未保存草稿和历史版本不算当前使用。
- 引用的来源入口：“引用时版本”与“查看当前来源”保留只读检查；“打开当前原文”进入真实编辑器，“并排编辑来源”保留采用稿并打开来源。已有编辑器优先复用，同一篇内直接定位。
- 使用处列表：点击后进入采用稿的对应引用块。打开前重新核对当前引用身份，已经移除或替换的引用不按旧位置或标题定位。
- 引用正文内的块链接：以来源作品和稳定块身份打开当前编辑位置，不再只弹出预览。不存在或存在歧义时报告失败，固定快照仍保留。
- 工作区后退／前进：携带发起位置；复用已打开页签时一并保留往返历史。定位会展开遮住目标的祖先，并短暂标出目标；减少动态效果时不播放高亮动画。

## 保存与中断

离开发起稿前使用宿主的保存会话。保存失败不继续跳转。关闭来源对话框、切换工作区位置或空间后，不执行迟到的定位结果。另一侧页签达到上限时明确报告，不静默替换已有页签。

定位服务只读取当前作品与结构化块身份，不更改内容。历史修订仅用于引用时预览，不授权把同名新块当作原目标。已打开编辑会话中的实时文档仍需再次校验目标，避免用已保存的旧位置跳到错误段落。

## 尚未覆盖

- 主工作区的图文与大纲已接入编辑定位；视频、社交稿和独立便签窗口未接入同等的跨宿主节点定位。
- 被引查询按当前活动文章分页，不是所有类型、草稿与历史修订的完整反向索引；按节点查询仅列直接指向该节点的引用，不推断包含它的整个文档或祖先分支引用。
- “并排编辑来源”不是双向同步引用。采用稿和来源各自保存、撤销与评论；固定引用通过明确更新重新捕获。尚未增加可互写的实时引用模式。
- 任意半句或跨块局部选文的精确捕获仍未实现；现有稳定块和完整范围语义不变。

本轮仅进行格式、静态类型、ESLint 与构建检查；未编写测试代码，未执行 UI 手动测试，不将源码接线视为真实界面验收。
