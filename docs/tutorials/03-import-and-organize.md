# 03：导入与整理素材

## 导入图片或文本

可以从开始入口、素材库或拖放区域选择文件，也可以粘贴支持的内容。导入工作区会先读取并展示待处理项目，然后再提交。

提交前检查：

- 删除重复或不需要的项目；
- 修正文本和元数据；
- 确认是“导入素材”还是“作为新创作输入”；
- 对被跳过或无效的项目查看原因。

确认后，应用把媒体写入当前空间的受管对象目录，并在 SQLite 中记录稳定身份。原始文件路径不是素材的长期身份，不要只备份外部源目录。

## 在图库中整理

导入后可以在图库中：

- 按素材、创作关系、收藏和评分查看；
- 把素材放入图集；
- 打开详情并回到对应创作或词条；
- 继续添加元数据、评注或引用关系。

删除或归档操作应从应用入口完成，避免直接删除 `objects/sha256/` 中的文件。直接删文件会让数据库记录和媒体可用性不一致。

## 导入词典 JSON/CSV

词典导入会先进行预检。确认前检查重复、无效行、名称语言、定义、分类和模型表达；确认后内容进入草稿，不会绕过当前词条的 revision 规则。

CSV 的表头和可接受字段应以当前导入界面和共享合同为准，不要再引用已经不在仓库中的 `tools/docs/v0.1` 文档。

## 导入内容包

内容包从内容包入口或开始页的导入操作进入：

1. 选择包含 `manifest.json` 的内容包目录；
2. 查看包名、版本、条目数和当前安装状态；
3. 确认导入或安装；
4. 在内容包页检查启用、停用、更新或卸载状态。

内容包不是本地空间。不要把 `content-packs/` 下的源目录直接作为“打开本地空间”的目标。
