# 04：维护词典与词盘

## 维护分类和词条

在词典维护入口中，先建立或选择分类，再创建词条草稿。编辑时重点检查：

- 主名称和名称语言；
- 其他语言的本地化名称；
- 定义、别名和模型表达；
- 分类、属性和代表性素材；
- 当前草稿是否已经保存。

分类支持树状的父子关系。移动、停用、恢复或合并前，先确认影响范围和关联词条；这些操作会影响浏览、筛选和 Prompt 选择，不应通过直接修改 SQLite 绕过界面。

## revision 与草稿

草稿是可编辑的工作状态；保存或核准后形成不可变 revision。需要修改已保存内容时，应创建新的 revision，不要改写历史版本。

如果词条缺少定义、分类或模型表达，先在维护视图中修复缺口，再把它用于正式 Prompt。历史词条仍可能被读取，但不代表它已经满足当前生成要求。

## 维护词盘

词盘用于维护可复用的 Prompt 内容节点和参数。保存词盘后，在创作台的 Prompt 选择器中引用当前 revision；不要把旧的自由文本快照当作词盘的权威来源。

使用词盘生成前确认：

1. 词盘 revision 已保存；
2. 当前 Prompt 语言与词条本地化可用；
3. 生成快照已经冻结；
4. 生成失败时只重试失败任务，不覆盖成功结果。

## 内容包和本地编辑的边界

内容包提供可分发的初始数据；本地词条和词盘属于当前空间。导入内容包后，先确认包来源和版本，再决定是否启用或继续本地编辑。
