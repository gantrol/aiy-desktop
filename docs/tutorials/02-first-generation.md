# 02：完成第一次生图

## 1. 准备模型连接

打开设置中的 AI 功能模型入口，进入 AI Center 的能力或连接配置。对需要凭据的扩展：

1. 启用对应扩展；
2. 按扩展要求填写 API key、模型和 endpoint；
3. 授予 manifest 声明的权限；
4. 执行连接测试，确认状态为就绪。

Codex App Server 使用已有的 Codex 登录态。OpenAI、DeepSeek 和其他图像 API 扩展需要各自的连接配置；切换模型不会替换或清除另一家服务的凭据。

## 2. 创建输入

在创作台新建创作，填写目标描述，按需要添加参考图、词典词条或词盘 Prompt。先用一张参考图和一次生成验证连接，确认可用后再扩大批量。

生成前检查：

- 当前选中的模型确实处于就绪状态；
- 参考图数量和格式符合模型限制；
- Prompt 已保存为当前版本；
- 不要把一次失败的结果当成成功结果继续编辑。

## 3. 查看任务和结果

生成后可以在创作台、任务状态入口或 AI Center 查看进度。成功结果会进入当前本地空间；失败结果应保留失败原因并只重试失败项。

结果落库后可以：

- 在结果之间切换和比较；
- 查看或添加点/矩形评注；
- 将结果导入素材库或图集；
- 重新编辑、生成相邻方向或继续创建新的 Prompt 版本。

窗口关闭时如果仍有模型任务，应用会提供继续后台运行、取消后退出、强制退出或返回的选择。需要确认恢复能力时，先让任务完成或明确取消，再重启应用检查任务和结果状态。

## 4. 常见失败处理

| 现象             | 先检查                                                   |
| ---------------- | -------------------------------------------------------- |
| 连接未就绪       | 扩展是否启用、权限是否授予、API key 和 endpoint 是否正确 |
| 网络或限流错误   | 网络、供应商额度和服务状态；不要只延长等待时间           |
| 参考图被拒绝     | 当前模型是否支持参考图，数量和 MIME 类型是否符合限制     |
| 任务卡住         | 查看 AI Center 状态；取消或等待明确终态后再切换空间      |
| 重启后找不到结果 | 确认打开的是同一个本地空间，不要删除或替换其 SQLite 文件 |

真实供应商验收至少要覆盖连接测试、一次成功生成、一次失败或取消、仅重试失败项、结果落库和重启恢复。
