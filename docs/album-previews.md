# 图集入口与无照片预览

图集采用集合标识、照片封面或真实内容预览。新建、选择目标、树节点和无照片封面不再使用文件夹图标。产品含义见 [AIY 图集设计](https://github.com/gantrol/aiy-docs/blob/master/design/pages/album.md)。

创作库的无照片预览复用当前已载入的直接成员及筛选结果：

- `creationAlbumContentPreviews` 按当前列表与形式次序取最多三项，按领域内容身份去重；跳过无法解析的内容，不额外读取正文或子图集。
- `AlbumContentCover` 显示与样本一一对应的类型标志。没有样本时保留单张空白轮廓；这表示没有可用预览，不能据此推断成员数为零。
- `AlbumContentCoverPreview` 在封面处直接展开相同样本：鼠标悬停或键盘聚焦展开，触屏点击封面展开，展开后的每个标志通过原有导航打开具体内容。名称与空白封面打开图集，树展开继续由原入口负责；行尾不再另设四格预览按钮或浮层。
- 移出预览区域且内部没有键盘焦点时收起；外部点击或焦点离开同样收起。Esc 收起并返回封面入口，内容导航或外部操作不抢回焦点。展开区域覆盖图集自身标题的局部空间，不移动相邻行或树连接点；保留连续命中区域、独立内容按钮与减少动态效果。名称及无障碍标签沿用现有语言资源。

本轮保持现有照片叠放及紧凑树节点的几何尺寸。面包屑仅替换为集合标识，照片预览仍待接入；详情、网格与素材入口仅统一无照片回退，尚未接入创作库的文字样本。成员关系、创建和移动事务、计数、数据库与版本号均未改动。
