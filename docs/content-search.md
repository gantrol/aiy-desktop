# 搜索原文定位

搜索工作面的“图片”类型使用独立的[本地语义图片搜索](image-search.md)，不进入下文的文稿身份与原文定位协议。

搜索结果的右侧正文和“打开来源”共用 `ContentSearchTargetContext` 传递来源身份与查询。搜索页在选择结果时保留查询；修改外层条件不改变正在编辑的正文的命中依据。新标签页将查询作为 `AppLocation.contentSearchTarget` 的临时导航信息，工作区持久化仍沿用已有阅读位置，不保存搜索装饰或字符偏移。

视频文稿预览复用视频文档工作区，按工作区容器宽度排列正文与来源面板：小于 `56rem` 时上下排列，来源面板最多占用 45% 高度并在内部滚动；宽布局保留可调节的左右分栏，来源面板最多占用 45% 宽度。正文区域限制溢出，字幕导航不会覆盖来源信息与操作。窄布局隐藏水平宽度调节柄，保留已保存的宽度供宽布局恢复使用。

`ContentSearchPosition` 在共享正文编辑表面中只挂载一次，避免双编辑窗格的工具栏重复注册编辑器插件。它按当前文档的文本块解析关键词和双引号短语，复用搜索结果的 Unicode 规范化和原文范围映射；行内格式不截断文字，嵌入引用不被当作来源正文继续搜索。多词分别标出正文中的实际出现位置，标题与正文共同满足检索条件时，不要求所有词都出现在同一段。

命中装饰只存在于编辑器视图，不进入正文、保存和撤销。修改原文后重新计算装饰；切换命中先显示大纲目标的祖先与范围，再滚动到文字。滚动请求可以取消，关闭查找、输入法组词、文档变化或更新的定位请求会使旧请求失效。显式搜索的初次定位优先于旧阅读位置；之后的显式正文导航仍生效。

本文内查找继续使用现有查找／替换控件，与结果定位共用展开和滚动逻辑。开始本文内查找会关闭此次搜索结果定位条，避免两套命中同时争夺当前高亮。界面沿用既有搜索、上下处、关闭与无匹配语言资源。

当前接入共享编辑表面的图文、大纲和社交稿可定位文字。视频的只读 Markdown、原视频时间点、媒体路径以及不在正文中的标题／ID 不宣称已实现文字精确定位。大纲查找结束后完整恢复查找前的折叠与聚焦状态，仍属于产品设计目标，不能由本次滚动修复推断已完成。
