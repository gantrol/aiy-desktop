# 图文稿手动新增与编辑 User Journey

状态：0.3.2 实现与回归基线
记录日期：2026-08-14

## 1. 范围与术语

本文覆盖用户不依赖 AI 生成、手动新增和编辑图文稿的主路径，以及编辑时插入普通图片和视频定位图片的路径。

“快速插入笔记”在本流程中指：以右侧源视频的当前播放时间截取一帧，并把该图片插入当前图文稿的编辑光标位置。它不会新建另一篇图文稿。需要精确选择时间或替换已有定位图片时，仍使用编辑器工具栏中的视频画面选择器。

## 2. Journey A：手动新增空白图文稿

前置条件：视频文档已有可编辑的图文稿 branch，且当前图文稿正文为空；隐藏的一级标题不算正文内容。

1. 用户打开“图文稿”页签。
2. 空白区域提供“编辑”和“生成图文稿”两个动作，不显示装饰性空状态或说明文案。
3. 用户选择“编辑”，进入所见即所得编辑器；工具栏和正文区域占满可用内容宽度。
4. 用户输入正文，也可以在“全部图文稿”中选择“新建图文稿”，再进入新图文稿的空白编辑状态。
5. 用户选择“保存修订”，系统提交新的不可变 revision，并返回阅读状态。
6. 用户选择“取消”时，丢弃尚未持久化的文字和媒体绑定；若编辑期间已经自动保存，则恢复到最近一次自动保存的版本。

结果：手动新增的图文稿可以独立保存，不要求先调用生成模型。

## 3. Journey B：自由上传图片

1. 用户进入任意图文稿的编辑状态。
2. “上传图片”是编辑器工具栏中的独立按钮；它不依赖源视频是否可播放、是否已取得时长，也不要求先打开视频画面选择器。
3. 用户选择 PNG、JPEG、WebP 或 SVG 文件；SVG 原件以 `image/svg+xml` 保存，位图解码仅用于安全校验与 DOCX 等位图消费边界。
4. 应用通过既有素材导入边界校验并持久化图片，再将图片插入当前光标位置；若当前选中一张图片，则替换该图片。
5. 普通上传图片的媒体绑定不带视频时间：`timestampMs = null`。
6. 保存时只保留仍被 Markdown 正文引用的媒体绑定。

失败恢复：文件不支持、导入失败或编辑器已经退出时，不插入损坏节点；用户停留在编辑状态并看到“无法上传这张图片”。

## 4. Journey C：从右侧视频快速插入笔记

1. 用户进入图文稿编辑状态，右侧源视频下方出现“快速插入笔记”。阅读状态、逐字稿页签和统一创作空白态不显示该按钮。
2. 用户播放或拖动视频到目标画面，并把图文稿光标放到目标段落。
3. 用户点击“快速插入笔记”。按钮立即进入忙碌和禁用状态，防止重复提交。
4. 应用以播放器当前的毫秒时间调用定位图片截取边界。
5. 截帧成功后，图片插入当前光标位置，草稿同时加入返回的图片媒体与带时间的媒体绑定。
6. 编辑器实例保持稳定，不因媒体数组变化而重建；格式状态、撤销栈和光标上下文继续可用。
7. 用户继续编辑并保存，新 revision 包含正文引用及对应媒体绑定。

失败恢复：截帧失败、源视频不可用或编辑器在请求期间退出时，不写入正文；忙碌状态恢复，编辑草稿保留，并显示“无法提取这个画面”。

## 5. Journey D：编辑与重新生成

1. 阅读已有正文时，生成动作显示“重新生成”；只有隐藏一级标题、没有可见正文时显示“生成图文稿”。
2. 对图文稿集合执行重新生成时，目标是当前选中的图文稿，而不是固定的默认图文稿。
3. 编辑、保存、图文稿集合变更或生成进行中，不允许并发触发重新生成。
4. 用户进入编辑后，重新生成动作让位于“取消”和“保存修订”，避免未保存草稿被模型结果覆盖。

## 6. Journey E：自动保存与版本历史

1. 图文稿工具栏提供“自动保存设置”和“版本历史”；自动保存默认开启，在用户停止修改 15 秒后触发，也可改为 5 秒、30 秒、1 分钟或关闭。
2. 每次正文或图片绑定变化都会重新计算闲置时间；同一时间最多执行一个保存请求，保存期间继续输入的内容不会被正在提交的快照覆盖。
3. 保存前比较当前 Markdown 与仍被正文引用的媒体绑定；内容没有变化时不创建重复 revision。最近一次自动保存已经覆盖全部更改时，选择“保存修订”只退出编辑状态。
4. 自动保存成功后继续停留在编辑状态，并把该 revision 作为“取消”的新恢复点；若请求期间又有输入，新输入仍标记为待保存并在下一次闲置后提交。
5. 自动保存失败时保留完整草稿和编辑状态，显示错误，并允许后续自动重试或用户手动保存。
6. 每次实际保存都追加不可变 revision，保留父 revision、连续版本号、内容哈希、来源和创建时间；不覆盖或清理旧版本。
7. “版本历史”从当前 revision 沿父链按页读取，标识当前版本、编辑保存／生成／系统来源，并显示相邻版本的新增行数和删除行数摘要；只有媒体或结构元数据变化时显示“正文无变化”。

## 7. Journey F：默认页签与图文稿切换

1. 再次打开同一文档时，优先恢复该文档上次停留的“图文稿”或“逐字稿”页签；不同文档分别记录，不能互相覆盖。
2. 文档没有页签记录且已有图文稿 revision 时，默认进入“图文稿”；没有图文稿但已有逐字稿 revision 时，进入“逐字稿”。
3. 两者都没有 revision 时，仍进入统一“创作”界面，不展示两个空页签。
4. 图文稿生成成功后进入“图文稿”；生成失败或缺少逐字稿时进入“逐字稿”，并通过可见错误消息保留失败反馈。
5. 阅读状态下，指针移入“全部图文稿”立即显示列表弹窗；正文保持原位，不再被列表替换。
6. 指针可以从按钮移动到弹窗内选择或重命名图文稿；选择后弹窗关闭并显示目标图文稿，移开按钮和弹窗后延迟收起以避免闪烁。

## 8. 状态与数据约束

| 场景                 | 必须保持的状态                                                     |
| -------------------- | ------------------------------------------------------------------ |
| 上传或截帧后媒体变化 | 不销毁当前 Tiptap editor，不访问已销毁 editor 的 `view` 或 `can()` |
| 普通上传图片         | 图片 binding 的时间字段为空                                        |
| 视频定位图片         | 使用 Main 返回的 binding 与准确时间，不由 Renderer 猜测路径或时间  |
| 保存                 | 通过 typed preload/IPC 保存完整 revision content                   |
| 自动保存             | 闲置去抖、内容去重、请求串行；成功后不退出编辑                     |
| 版本                 | 每次实际保存追加不可变 revision，旧版本保持可读取                  |
| 取消                 | 不提交未保存草稿，不保留只属于未保存草稿的 binding                 |
| 异步操作             | 操作结束、失败或编辑器退出后都解除忙碌状态                         |
| 默认页签             | 按文档恢复上次页签；无记录时图文稿 revision 优先                   |
| 全部图文稿           | 悬停弹窗不替换正文，允许移入弹窗完成选择与重命名                   |

## 9. 验收与自动化映射

| ID    | 验收场景                                       | 自动化重点                                         |
| ----- | ---------------------------------------------- | -------------------------------------------------- |
| MJ-01 | 空白图文稿可手动进入编辑并保存                 | 空白动作、编辑状态、保存内容                       |
| MJ-02 | 图片可脱离视频画面选择器自由上传               | 独立按钮、素材导入、无时间 binding、保存过滤       |
| MJ-03 | 编辑时可从右侧视频一键插入当前画面             | 按钮可见性、当前时间、单次截帧、光标插入、忙碌状态 |
| MJ-04 | 媒体状态更新不触发 `Editor.can()` 空 view 崩溃 | 同一 editor 生命周期内更新媒体并继续执行格式命令   |
| MJ-05 | 截帧或上传失败可恢复                           | 无正文污染、错误反馈、忙碌状态复位                 |
| MJ-06 | 重新生成作用于当前图文稿                       | 标签、选中 note ID、并发禁用                       |
| MJ-07 | 闲置后仅保存发生变化的草稿                     | 延迟设置、去抖、内容签名、单请求串行               |
| MJ-08 | 自动保存后保持编辑并保留后续输入               | revision 同步、保存基线、请求期间继续输入          |
| MJ-09 | 历史版本可分页查看并显示相邻差异               | 父链顺序、来源、时间、新增／删除行数               |
| MJ-10 | 默认进入有内容的图文稿并按文档恢复上次页签     | 首次优先级、逐文档持久化、空白创作态、失败回退     |
| MJ-11 | 悬停“全部图文稿”直接显示列表弹窗               | 零打开延迟、正文不替换、弹窗移入、选择后关闭       |
