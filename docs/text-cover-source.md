# 文字封面样张参数

文字封面可以随文章修订保存排版来源：采用后，重开文章、点击对应画幅的封面即可继续改字和排版，不再要求用户手动找回参数文件。参数导入／导出仍可单独使用。本功能复用文章保存、修订、恢复与撤销，不新增作品保存层，也不是通用设计内容包、可执行模板或字体管理器。

既有 `TextCoverRecipe` 只是文字封面的排版参数，不是词典中的制作配方。此处复用该参数结构，不新增一套跨领域配方存储。

## 文章内保存与继续编辑

每个 `coverVariants` 项可以带可选 `textSource`，使用同一版本 1 参数合同，画幅必须与该项一致。参数描述 `sourceAssetId` 对应的文字封面；`assetId` 仍指向实际采用的图片，裁切由原 `crop` 单独表达。开始生成时固定一份参数，用它生成图片并在一次封面修改中采用，不能把后续编辑的参数配给已经生成的旧图。

采用之后源参数进入原文章修订、自动保存、恢复副本和封面撤销历史。旧修订不重算，也不由模板或文章标题的更新自动改写。新的可选字段不改变无源参数旧稿的内容哈希，不增加 SQL 迁移。旧版本程序的严格校验器不认识新字段，降级不在本切片的保证内，不能绕过校验把字段删掉再保存。

固定画幅入口恢复该画幅的已存文字和参数。通用入口也按画幅载入；在同一次弹窗中切换画幅保留各自的临时调整，尚无设计的画幅以当前设计作为起点，但不会覆盖已存设计。按钮明确为“采用当前画幅”，只采用当前一份；其他未采用调整只属于本次弹窗，关闭即放弃，不声明已保存。

点击有文字来源的封面，直接进入“编辑文字封面”；选图和裁切仍有独立入口。裁切同一来源图保留源参数；替换为不同图片或生成结果时不携带旧图片的文字来源。再次从文字来源生成时重新生成该画幅的完整设计并居中采用，不沿用上一次栅格裁切。只替换选定画幅，不顺便替换其他画幅或公共封面。

替换文字封面后，从当前稿的媒体绑定中移除已不再使用的旧文字图；正文、参考材料、公共封面或其他画幅仍使用的图继续保留。这里不删除素材文件及历史修订，撤销可以重新加入原绑定。

没有 `textSource` 的旧 PNG 不推测其文字或排版，不把 OCR 或文件名当作设计源稿。保存时的具体字体当前不可用，继续保留已存图片与参数，显示字体缺项并暂停生成，用户明确换为可用字体后才能采用。通用字体栈仍只保证参数含义，不保证跨机器像素一致。

## 文件合同

`aiy.text-cover-source`、版本 `1` 保存标题、画幅及现有布局、装饰、配色、字体标识、字重、字号系数、行距和边距参数。导出固定当前值；不存组件状态、随机种子、主库身份、机器路径、凭据或字体原件。预设的内部 ID 不进入文件。

文件至多 64 KiB，标题至多 1000 字符。读取前检查文件大小，读取后检查实际字节数；严格解码 UTF-8，允许 UTF-8 BOM，拒绝损坏编码而不是替换标题字符。导入使用现有 Zod 严格校验版本、枚举和数值范围，拒绝未知字段、未来版本及任意 CSS／脚本。版本 1 的画幅、布局、装饰、配色和字体标识在文件校验中以字面量固定，不随运行时菜单增删改变。新增标识需要新格式版本和明确迁移，旧标识仍须保留其参数含义及消费者。数据不授予联网、执行或安装权限。

## 编辑与失败

选择文件后通过 `FileReader` 异步读取；关闭或切换封面上下文时中止尚未结束的文件读取、释放监听，并使旧请求失效。复用的字体探测不因此取消，但迟到结果不能再建立候选。同一会话不启动重复读取；关闭预览也取消未结束的读取意图，不能仅隐藏预览后又由旧结果将它打开。读取期间暂停修改和采用，仍可关闭弹窗。读取与图片采用分别管理忙碌状态，旧读取的清理不能解除图片写入保护。有效输入先形成预览，确认后才整体替换本次弹窗的标题、画幅和参数，取消不改原输入；真正写入文章仍走原 `onApply` 和 `COVER_CHANGED` 检查。

锁定画幅的入口拒绝其他比例，不静默缩放。内置预设统一使用通用字体栈，包含 technical 预设，避免缺少微软雅黑时能导出却不能重新导入；具体本机字体仍由用户从已探测到的选项中选择。指定本机字体未检测到时拒绝本次导入并保留原稿，不默默替成系统字体。通用字体栈可使用已声明的回退，但不保证跨机器字形、字重、覆盖或像素相同。溢出检查继续使用已有渲染器；参数文件可保留尚需调整的设计，不因导出成功宣称图片可用。

导入确认的预览提供可访问名称，包含文件标题、画幅、布局、配色、装饰、字体与字重，复用对应语言资源。界面保留预览、画幅及确认／取消动作；参数与字体文件的边界在本文维护。

下载仅表示发起文件保存请求，不能报告磁盘已保存；真正持久化结果由用户确认。文件仍不包含字体、许可或完整编辑工程。只有在文章中采用文字封面时，参数才随对应文章修订保存；独立 PNG 和外部 Markdown 导出不因此自动具有可编辑源稿。

## 对应位置与后续

`shared/contracts/text-cover-source.ts` 维护跨进程参数合同，主进程不依赖 renderer。`textCoverSource` 保留浏览器文件读取、参数捕获与下载请求；`useTextCoverSource` 负责导入、字体条件与迟到隔离；`useTextCoverDrafts` 管理单次弹窗中各画幅的临时稿。操作菜单和确认面复用 shadcn。界面文案来自 `useI18n().messages.textCoverSource`，英文与简体中文一同维护。

格式及渲染语义更新时保留版本 1 的明确解释；不能以后仅替换内置配色而声称旧样张像素不变。完整的字体字节、模板修订和依赖固定属于后续内容包能力，本批不升级应用、SQL、宿主或插件版本。

验证需区分类型、格式、lint、构建、已有自动检查与真实 UI、文件对话框、图片导出及平台交付验收。详细测试代码与运行证据归私有测试仓；通过静态检查不表示交互或跨设备字体已完成验收。
