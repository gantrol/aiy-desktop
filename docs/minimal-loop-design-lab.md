# 最小创作循环：正式组件接入切片

## 基准与范围

接续独立工作台提案，基于 `e9f3e7c362e1ed50ab29107483e75d833a327d69`。页面是 Design Lab 中可编辑的设计样例，不替换桌面生产入口，不迁移真实作品、数据库或发布合同。

入口：`design-lab/minimal-loop.html`。沿用 `npm run design:dev`，打开 `/minimal-loop.html`；`?locale=en` 使用英文界面。`npm run design:build` 的既有多页入口包含本页。机器可读索引位于 `design-lab/minimal-loop/manifest.json`。已有 `cases.json` 管理媒体组件夹具，未将工作区页面冒充为同类媒体夹具。

## 从便携样例向前走了什么

- 直接导入正式 `styles/index.css`、shadcn Button/Input/Dialog、`useContentEditor` 和 `ContentDocumentOutline`。不复制旧 React、替代控件、主题快照或样式覆盖。
- 正文使用真实 BlockDocument 和编辑器会话；目录是同一文档的投影，不再维护平行的字符串正文和自制节点编辑器。
- 首次访问才创建作品编辑器；返回已访问作品复用同一会话。面板偏好与容器临时变窄分开；容器重新容纳面板时关闭临时弹层，保持原收展偏好。输入与目录共用中间左区，从弹层切换作品或定位正文后将焦点交回编辑器。原生滚动与焦点行为仍须单独验收。
- 材料由作者逐项明确选择；打开主题、浏览未选材料不会把它们加入当前稿件输入。选集按作品保存于本页内存。
- “另存为产出”固定当前内容和本次选材，记录原作品及本页会话修订。“平台稿”准备公众号、小红书草稿，保留固定基准，收在各自原稿下面；再次选择同一渠道打开已有草稿，不覆盖人工修改。没有发送或“已发布”状态。
- 导出 Markdown 或带来源和选材的 JSON。JSON 明确标记 `productImportFormat: false`，不授予模型执行、仓库写入或发布权限；不是产品导入格式、完整任务交接包或已发布文件。

UI 复用 `messages.designLab.themeCreation`、`messages.referenceOutline` 和既有语言选择标签，均通过 `useI18n().messages` 获取；未新增文案，因此不增补或拆分英文基准与中文语言包。派生稿保存作者标题、来源及渠道标识，展示时解析派生标签；错误保存稳定标识，展示时解析当前语言。切换界面语言不翻译作者写下的样例内容。

## 提案内容仍然保留

`plan.json` 保留上一版 40 项特性、9 个场景、18 项业务验收的稳定 ID、优先级、顺序、依赖、处置方式、加回条件及关联。这是作者可修改的产品提案，不是测试代码、合成测试夹具或已执行的验收报告。

“特性、场景与验收”作品按原优先顺序组织特性，使用正式目录查找。当前文档内可解析的关联使用真实块锚点；快照以外的目标只保留标识，不伪造可跳转目标。特性条目存在不表示该特性已实现。

## 结构核对后的接续边界

本页可作为正式组件与编辑会话接入的参考，但不能直接当作已经收敛的创作结构。共同产品建议在 [aiy-docs 的最简创作结构](https://github.com/gantrol/aiy-docs/blob/master/design/interactions/creation-modes.md#最简创作结构的收敛建议)维护，源码与历史状态的核对在其实现基线维护。

- `WorkEditor` 对所有样例使用正文编辑器，`ContentDocumentOutline` 提供正文标题目录，没有提供独立大纲的条目编辑工作面。样例中“大纲与正文沿用同一份内容”只可用于准确的同稿关系，不能概括独立大纲与由它加工出的文章。
- `InputsPanel` 同时列出可选材料和选中态，没有单独呈现仅含本次选集的工作区；尚未接通选段、条目引用与来源返回。明确选择材料的现有行为继续有效。
- `planDocument()` 从 `plan.json` 单向生成文档。页面内文稿编辑不会更新原清单的优先级、依赖或加回条件，也没有结构化任务交接；保存原始 JSON 和提供块锚点不代表这些功能已经接通。
- `derive(channel)` 和独立另稿共用复制实现。样例保留来源会话修订和人工修改的价值，但生产渠道适配须沿既有 Mask 合同，不能直接迁移成多个独立 `Work`。

接续时先选一段真实创作用例，明确原件、选材、当前作品、加工结果和渠道差异的关系，再复用相应的领域编辑与保存能力。不得仅给本页追加更多按钮、对象类型或持久化，就宣称“最简模式”已经成立。

## 与上一版演示的差别

本切片专注正式编辑会话、来源基准与四区外壳；没有把独立预览的演示稿、特性筛选表或 Codex 任务导出器原样复制进产品。自制大纲拖拽、缩进代码也不进入仓库：正文及目录沿现有组件能力工作。完整独立大纲工作面、逐块采用来源、PPT、模型任务、渠道校验和真实交接需分别接入既有领域合同。

当前内容仅留在页面内存，刷新会回到样例；没有持久化、重新导入或跨重启恢复。派生作品的来源基准是此样例的会话修订，不冒充数据库修订。隐藏的已访问编辑器留存以保留撤销栈，但不会后台加载用户资料；本实现不是大量作品下的内存或性能验收结果。
