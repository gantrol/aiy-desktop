# 创作参考资料面

2026-10-09 核对。参考资料入口已完成收敛，并按作者新要求接入 EPUB 图文阅读、选段与回源。独立处理／积累和结构化笔记界面继续保持移除。产品范围见[创作内容区](../../../aiy-docs/design/pages/creation-content.md)及[MVP 路线](../../../aiy-docs/product/creation-input-research.md#mvp-路线与功能取舍)。

## 当前入口

已有图文／大纲的原工具栏增加「参考资料」。正文默认占满内容区，打开资料后支持左右、上下或单面查看；布局放在资料面头部。正文编辑器保持挂载，引用到末尾使用原编辑器撤销。

资料面只提供来源切换、打开本地文件、阅读、选段引用和普通笔记。笔记按需在资料面下方展开。移除四阶段顶部栏、选集勾选、独立整理稿、另存整理结果、积累查找、康奈尔和只看问题的组件、动作及文案。

本地 HTML 沿用内容内静态／离线运行查看和文字抽取。PDF 保留分页画布及本页文字视图；TXT／Markdown 以文字查看。EPUB 改用排版引擎在资料面连续阅读，原来的纯文字章节实现与 fflate 依赖不恢复。

## EPUB 阅读

打开 `.epub` 后按阅读顺序连续显示图文，保留本地样式、图片、表格、书内链接和可用字体。目录支持 EPUB 3 导航及 EPUB 2 NCX；目录缺失时按书脊顺序提供章节入口。资料面只增加目录、字号、上一页／下一页；Page Up／Page Down 在阅读正文中滚动一屏。书页使用浅色纸面，外围工具栏沿应用主题。

直接在排版正文里选文，继续使用已有「记笔记」「引用到正文末尾」。选段位置存入 `ReadingLocation.epubCfi`；最近阅读位置及字号存入 `ReadingPosition.epubCfi/fontSize`，查看模式为 `EPUB`。恢复和字体／容器重排基于 CFI；选文操作栏出现造成的容器变化也恢复选区。回源在实际渲染的段落核对原文再选中，避免把偏移不符当作定位成功。

引擎为 EPUB.js 0.3.93，延迟加载。归档读取由 JSZip 3.10.2 worker 按需串行解压，最多排队 64 个请求，并在输出流中核对实际展开量；章节离开渲染窗口后卸载其文档，收起／切换时终止 worker、销毁排版会话并撤销 Blob URL。DOMPurify 3.4.16 清理章节和 SVG，书内资源只从当前归档解析，CSS 的本地资源转为受控地址。

章节写入禁止脚本和弹窗的 sandbox iframe 初始文档，附加限制图片、字体、样式、表单及网络的 CSP；未扩大应用的 CSP、导航允许范围或 IPC 能力。禁止书内脚本、联网资源和外部链接自动打开。依赖覆盖将 EPUB.js 的旧 XML 库约束到 `@xmldom/xmldom` 0.9.12；浏览器端仍使用原生 XML DOM。

本轮范围是未加密、可重排的 EPUB。支持标准 IDPF 字体混淆；不提供 DRM 解密、固定版式、音视频／互动脚本和跨章节一次选文。旧摘录没有 CFI 时保留文字并提示无法精确定位，不猜测旧字符偏移。复杂出版物、竖排、屏幕阅读器及真实长书阅读尚未专项验收。

实现依据：[EPUB.js API](https://github.com/futurepress/epub.js/blob/v0.3.93/documentation/md/API.md)、[JSZip 流读取](https://stuk.github.io/jszip/documentation/api_zipobject/internal_stream.html)、[EPUB 字体混淆规范](https://www.w3.org/2019/epub32/epub-ocf.html#sec-resource-obfuscation)。它们是技术参考，不是本应用的运行验收证据。

## 保存兼容

新的 `ArticleContent.reading` 写来源、当前来源、普通笔记、正文引用关系与各来源的最后阅读位置。它们随作品修订、自动保存和恢复保全，没有新增或修改数据库迁移。

旧的 `noteMode`、`processing`、`cue`、`summary`、`selected` 只作为可选的历史字段读取和原样保留，新功能不创建这些值。旧笔记的问题、记录和总结合并显示为普通文本，用户编辑后保存到 `text`，避免隐藏旧文字。文字上限可容纳原三个字段的合计容量。

旧 EPUB 来源沿已有文件身份重新读取，原文件、摘录和笔记不删除；旧范围缺少新定位信息时不会自动补造。旧整理稿仍在原修订数据中，撤下界面不会清空它；当前界面没有专门的恢复编辑入口。未对真实用户数据库执行批量迁移。

## 选段引用与返回

「引用到正文末尾」追加所选文字及可点击出处，复用正文的编辑事务与撤销。出处采用作品内的 `#aiy-reading:` 片段链接；来源身份、页／章及文字范围、原文快照记录在 `reading.citations`。正文与引用关系进入同一次保存快照；撤销后保留关系以支持重做，删除笔记不影响已插入的引用。

点击出处，或将正文光标移到链接上按 Ctrl／Command + Enter，在当前作品的参考资料面打开对应来源。选中前逐字核对保存范围与原文，匹配后显示片段；范围失效或原件不可读时保留已保存文字并提示，不搜索相似段落冒充成功。PDF 引用进入对应页的文字视图，本地 HTML 引用进入抽取文字视图，EPUB 使用排版正文的 CFI 范围。笔记回源也使用同一核对规则。

资料面头部提供返回动作，恢复核对前的来源与阅读位置；从正文进入时恢复编辑器焦点及之前的资料开关状态。关闭资料面也可回到正文。首次未滚动的来源以开头作为返回位置，避免查看引文后无法回到起点。

阅读位置按来源保存，滚动变化经过 600 ms 合并写入；切换来源、关闭资料及工作区保存退出时先提交待保存位置。文字尽量保留视口附近字符偏移，PDF 记录页码、查看模式与滚动位置。关闭或隐藏资料面卸载读取器，重新打开时从保存状态恢复，不自动运行网页。

当前链接只在原作品内解析；复制到其他作品或导出到外部编辑器后，不提供跨作品／外部回源。旧纯文字出处不自动升级为链接。字符偏移仅适用于所保存来源的文本版本；PDF 缩放比例未持久化，页面视图的像素位置不保证在窗口缩放后精确一致。

## 技术边界

文件导入／读取继续通过当前空间与作品来源身份校验、大小及哈希验证、异步 I/O 和受限在途操作。PDF／EPUB 32 MiB、TXT／Markdown 1,000,000 字节，HTML 沿用既有 4 MiB 限制。作品资料元数据整体限制 2,000,000 个 JSON 字符，每份作品最多 30 个来源、100 条笔记记录、300 个引用关系与 30 个来源位置；单次引用最多 30,000 字符。

EPUB 最多 5000 个归档条目，已读取的不同资源合计最多展开 128 MiB；单资源 16 MiB，单文档 2 MiB／30000 个元素，单样式表 512 KiB。读取设超时与取消，拒绝路径穿越及外部资源解析。这些是容量保护，没有进行耗时或内存的前后对比，不作为性能提升结论。

HTML 文字抽取使用独立 worker。PDF.js 按需加载，worker、CMap 和基础字体随应用打包，不扩大网络与 CSP 权限。特殊 PDF 编码和复杂内容的兼容仍未完整验证。

网页运行保持既有权限、离线隔离和单运行槽。关闭或隐藏资料面会停止运行，选择来源或布局时回到文字，原生视图受内容区域裁切；重开作品不自动执行脚本。

## MVP 尚需核对的缺口

目前入口仅接入已有图文／大纲，自由新建草稿尚未完整接通。网页选文来自抽取文字，PDF 选文来自本页文字视图；直接在原排版中选文、扫描识别、跨页选区和跨版本定位均不应宣称已完成。正文回源与阅读位置保存已接线，其新交互缺少直接自动化覆盖，尚未进行真实资料与界面验收。

MVP 应用同一份资料和作品验证阅读、选段、笔记、引用、保存重开及回源。EPUB 的上述路径已经接线，但现有自动化没有直接覆盖新排版会话、CFI、解包限额与资源过滤；实现完成不能代替实际资料验收。
