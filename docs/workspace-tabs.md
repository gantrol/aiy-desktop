# 工作区与页内标签

共同设计见 [标签方案](https://github.com/gantrol/aiy-docs/blob/main/design/interactions/workspace-tabs.md)与[标签及分段控件](https://github.com/gantrol/aiy-docs/blob/main/design/surfaces.md#标签与分段控件)。本页记录 renderer 的职责与接入边界。

## 顶行与侧栏

`AppWorkspaceGroup` 通过 `WorkspaceHeader` 让 `WorkspaceTabStrip` 独占所属工作区或分屏窗格的完整一行。创作库与共享 `WorkbenchSidebar` 的头部留在下方各自侧栏中；展开、收起窄轨、直接调宽及页面没有侧栏时都不改变标签条起点。

侧栏内容、头部控件、筛选、选择与编辑会话都留在原标签 DOM 内，挂载数量沿用现有上限，不建立共享创作库状态。最后焦点直接记录在标签内容面；工作区快捷键沿原入口恢复，不再维护脱离内容面的侧栏头部焦点容器。

隐藏标签仍保留已测得的侧栏几何，供下方内容分栏与切换动效使用；目标页测量与登记的中间值不会改变标签条宽度。整屏加载尚未确定布局时沿用已有侧栏几何。素材导航的“素材／词典”切换继续占据自己的侧栏头部，不再与重复标题上下排列。

创作、素材、词典、搜索及复用共享适配器的集合侧栏使用同一头部与窄轨；主体内的嵌套集合不注册为外层侧栏。分屏各有自己的整行标签，原有窗格折叠与保存保护保持独立。本文不把窗格收起视为仅收起标签标题，也不把视觉改动视为侧栏全局共享。

`WorkspaceTabItem` 使用内容类型图标、可聚焦的完整标题提示和加载图标；普通标签预留关闭槽位，置顶项呈现见下节。按后续反馈去掉页签顶部强调线：活动窗格普通标签为 500、当前页为 600；非活动窗格全部为 400，并保留自己的选中轮廓。状态复用原有 `active`，键盘焦点仍有独立轮廓。置顶与菜单操作见下节；普通标签保留横向滚动，全部标签菜单仍沿现有入口，搜索、重名消歧与误关恢复未在本批新增；拖动见[标签拖动与置顶形态](#标签拖动与置顶形态)。

选中的普通页签采用已选 C 曲线。`WorkspaceTabShape` 由两个固定宽度的镜像 SVG 端部与可伸缩中段组成，保留平顶、轻斜边和底部外展；沿现有主题绘制单条边界，不使用整张 SVG 的横向缩放改变曲率。装饰层禁用指针事件并从无障碍树隐藏，按钮维持独立焦点与点击区域。展开态标签条两端预留外展空间，标签滚动边距同时考虑曲线和关闭按钮；置顶项和收起窄轨不套用曲线。轮廓绘制不需要 DOM 测量或额外的共享样式变量。

## 置顶与标签操作

`WorkspaceTabItem` 的右键菜单提供置顶／取消置顶、“移动到…”位置子菜单、移至首尾、跨窗格移动，以及关闭当前、其他、两侧和未置顶标签。按作者要求移除单步左右移动，竖向收起栏也移除对应的上下移动项；位置子菜单列出同区其他标签，选择后移到该项之前。菜单置顶追加到置顶区末尾，解除后进入普通区最前。

置顶项在展开标签条中固定为 32×28px，在横向或竖向收起栏中为 28px 方形，居中显示 14px 的内容类型图标；没有传入类型图标时使用工作区图标兜底。常驻项与更多入口复用 `workspace-pinned-tab-styles.ts`：默认透明，悬停使用轻底色，选中使用小圆角底色与完整细边框，取消曲线外展及开放底边。独立置顶区及展开列表不叠加图钉角标。标题和置顶状态保留在无障碍名称中，常驻图标悬停或键盘聚焦仍显示完整标题提示。置顶项不显示关闭按钮，真实切换等待时在同一位置显示加载图标；菜单、中键与键盘关闭沿原入口。全部标签菜单仍显示标题和图钉，取消置顶恢复普通标签的标题与关闭槽位。

`workspace-state.ts` 统一管理排序、移动与关闭范围；跨窗格移动和合并后稳定排列置顶项。`WorkspaceTabDto.pinned` 是可选布尔值，运行时与布局快照双向保留，旧快照省略该字段时按未置顶处理。沿用现有按空间保存的布局文件及异步写入，不新增数据库迁移。

`useWorkspaceActions` 先对批量关闭对象逐一执行已有保存保护，全部通过后才提交布局变化；置顶项不进入批量关闭与保存确认队列，明确单项关闭仍可执行。确认期间空间、活动页、排列或置顶状态改变时取消旧请求。关闭后保留仍有效的活动标签；仅剩一个工作区入口时沿原规则创建起步标签。菜单高度受可用窗口限制，关闭后仅在焦点没有转往其他有效控件时恢复标签焦点。

### 独立置顶区

`WorkspaceTabStrip` 在共同标签导航内将置顶区和普通标签滚动视口分开。置顶图标项间距保持 2px，横向栏垂直居中，起始留白为 4px；区域之间复用 `Separator` 显示 16px 的居中短细线。置顶区最多三个常驻位置；超出时显示前两个图标和更多入口，不显示剩余数量。更多入口通常显示省略号，当前置顶页被收起时改为该页类型图标及 8px 展开箭头，并保留选中底面；点击仍展开列表，不自动重排置顶项。`useWorkspaceTabLayout` 观察扣除工具区后的标签视口，按新尺寸、项间距、分隔及视口留白计算常驻数量，在窄分屏或较短竖向栏中减少常驻位置，展开入口计入上限；无置顶项时不预留区域。

`WorkspacePinnedTabs` 使用已有 Popover、Button 和标签右键菜单展示全部置顶项及完整标题，复用原切换、关闭、移动及保存保护。`PopoverAnchor` 以整块置顶区作为对齐基准，横向栏朝下展开，竖向收起栏朝内容侧展开；宽度按内容在 14–16rem 间调整并受可用空间限制，长标题换行，高度受窗口约束。浮层不改变标签条尺寸。当前项用字重和独立勾选标记，悬停底色与键盘焦点分别表达；更多入口的无障碍名称包含当前完整标题，面板继续引用对应隐藏标题，不生成重复标签 ID。

每行复用 `ItemActions` 提供取消置顶按钮，预留行尾槽位，悬停、聚焦或触控输入时显示。标题与取消置顶是两个并列按钮，不嵌套，不让取消置顶同时激活或关闭内容。解除后仍有溢出时保持列表，焦点移到相邻行；更多入口消失时关闭浮层并沿原导航恢复到有效标签。菜单移动、保存保护和原有布局字段保持不变。

悬停沿 `useHoverIntent` 的 180ms 延迟，预览不转移编辑焦点；点击、触控或键盘打开后保持交互，列表内方向键移动焦点，Enter／Space 激活，Esc 关闭。子右键菜单与浮层间移动不关闭父层；关闭时仅恢复到仍有效的入口，不覆盖新交互层的焦点。`useWorkspaceTabStripNavigation` 管理常驻图标、更多入口和普通标签之间的方向键，以及收起或移除后的焦点恢复；工作区快捷键的内容焦点兜底也能到达更多入口。

中英文资源提供“更多置顶标签”、包含当前标题的展开名称及包含目标标题的取消置顶名称；使用现有语言目录插值。没有改变标签容量、会话挂载、持久化或应用版本。

## 工作区切换动效

标签移动的局部动效见下节；这里的选中切换仍保持独立。

`WorkspaceTabShape` 的装饰层在展开态保持挂载，通过选中状态和 Tailwind 的透明度过渡呈现、隐去曲线，复用 `motion-fast` 与 `ease-standard`。隐藏装饰不接收指针事件，也不进入无障碍树；收起窄轨沿用颜色过渡。

`AppWorkspaceGroup` 切换可见会话时直接显示工作面。同类侧栏宽度不同时，`WorkspaceSidebarMotion` 过渡下方侧栏整体及内容边界；本地侧栏头部随侧栏一起变化，工作区标签条不参与宽度过渡。目标没有同类侧栏时仅原侧栏淡出。原来的整页 `workspace-tab-reveal` 不恢复，标签轮廓的局部反馈保留。

没有移动或复制编辑器，不合并标签状态，也不改变原有 `hidden`、`inert`、会话挂载上限、保存保护和导航提交时机。共享集合侧栏的收展与直接调宽分开处理，接入范围和未验证项见[工作区动效实现](workspace-motion.md)。不能据此认为创作页全部面板、大纲和图片预览已接入新动效。

## 标签拖动与置顶形态

`useWorkspaceTabDrag` 为每个窗格持有一次指针手势，`workspace-tab-drag-session` 管理阈值、跨区停留、浮层展开、取消与清理，几何计算集中在 `workspace-tab-drag-geometry`。普通条、固定置顶区和置顶浮层登记各自的排序轴；只接收所属窗格的落点，正文、工具按钮和其他分屏不能提交移动。关闭及行尾解除置顶按钮不是拖动起点，触控继续使用滚动和菜单。

超过 6px 才进入拖动，跨置顶边界停留 280ms 后就绪；更多入口用同一次停留打开完整列表，并允许跨过入口与浮层之间的短间隙。列表在手势期间保持打开，普通区与列表沿边缘延迟滚动且速度有上限。无置顶项时临时显示置顶落区，拖动预览不改变实际成员，因此常驻数量与更多入口位置保持稳定。

预览只移动标签外观和邻项；`WorkspaceTabPlacement` 携带目标置顶状态、后继标签身份及开始时的排列签名。`reorderWorkspaceTab` 核对同一窗格当前签名后一次提交顺序和置顶状态；无效、过期及空操作返回原状态。活动页、历史、草稿和正文不变，继续沿原布局保存链路持久化，没有新增 IPC、数据库迁移或逐帧保存。

跟手层只包含图标与标题，忽略交互并退出无障碍树；邻项约 150ms 让位，落位与置顶形态约 180ms，取消回程约 120ms。菜单操作由 `useWorkspaceTabMotion` 捕获前后位置，置顶形态使用不承载交互的图标和文字副本；文字及图标不缩放。减少动态效果直接呈现终态。新手势、失效布局和卸载清理监听器、滚动帧、预览样式和动画，焦点恢复不等待动画完成。

现有相关回归覆盖原导航与布局基础行为，不能替代新增拖动的专项验收；浮层跨区、三／四项切换、真实 DPI、减少动态效果及动画观感仍没有直接运行验收。中英文文案共同维护位置子菜单和移动结果，菜单继续提供精确排序的点按与键盘替代。

## 页面与面板

`components/ui/tab-styles.ts` 维护细线选中外观。`TabsList` 提供普通与紧凑密度，`Segmented` 的 `appearance="line"` 复用同一视觉；Tabs 的内容面板关系与 Segmented 的值选择语义分别保留。

`CodexArtifactsScreen` 的页内导航与任务历史、用量侧栏共享 Grid 列；侧栏跨越导航行和内容行，导航只占主体列。组件内的关系选择器与 `subgrid` 沿用侧栏实际宽度，不增加独立偏移测量，也不移动导航 DOM。窄布局将侧栏放回内容行，恢复按钮复用导航条的 portal 容器。历史与用量通过 `Activity` 保留已访问状态，隐藏栏目释放外层侧栏几何登记。此布局仍需实际窗口缩放、拖动和键盘焦点的 UI 验收。

基础 Tabs 消费者共享字号与状态；AI 中心、扩展中心移除各自的标签高度覆盖，素材检查器采用紧凑密度。素材／词典切换和创作产出模式采用细线外观。产出区有空间时显示短名称，窄栏保留图标和键盘可达提示；内容辅助面板按可用宽度显示名称或整组仅图标，收起窄轨使用图标，方向与明确激活由原 Tabs 管理。语言、布局及筛选仍为分段选项。

`ContentWorkspacePanelNavigation` 在面板操作之外测量标签可用宽度，以不参与交互的隐藏行测量当前语言的完整标签，并按选中字重预留空间。`ResizeObserver` 同时观察可用宽度与测量行，覆盖拖动、分栏、字体和语言变化；恢复文字前预留 8px，避免临界宽度反复切换。布局变化复用原标签按钮，保留提示、无障碍名称与选中状态；隐藏测量行不进入无障碍树。极窄时保留图标横向滚动作为访问兜底，并明确关闭标签栏纵向滚动。

外观沿现有主题、i18n 与减少动态效果设置；置顶使用上文的可选布局字段，未增加主题、版本或依赖。
