# 工作区与页内标签

共同设计见 [标签方案](https://github.com/gantrol/aiy-docs/blob/main/design/interactions/workspace-tabs.md)与[标签及分段控件](https://github.com/gantrol/aiy-docs/blob/main/design/surfaces.md#标签与分段控件)。本页记录 renderer 的职责与接入边界。

## 顶行与侧栏

`AppWorkspaceGroup` 通过 `WorkspaceHeader` 协调集合侧栏头部与工作区标签条。`CreatorScreenView` 与共享 `WorkbenchSidebar` 提供各自布局计算的结果，顶行和内容边界复用同一插值宽度；多栏中展开与收起窄轨均参与对齐，单栏布局或侧栏完全隐藏时恢复整行标签。

每个已挂载的标签都有独立头部容器，`CreationLibraryHeader` 只将头部控件 portal 到对应容器。普通标签切换保留同一个 portal 目标，避免因移动头部重新挂载搜索框；非当前容器隐藏且 inert。侧栏内容、筛选、选择与编辑会话仍属于原标签，挂载数量沿用现有上限，不建立共享创作库状态。标签头部和正文共同记录最后焦点，工作区快捷键沿原入口恢复。

这些容器放在同一个持续挂载的头部外框内。隐藏标签仍保留已测得的侧栏几何，目标页测量与登记的中间值不单独改变标签条位置；整屏加载尚未确定布局时沿用外框宽度。素材导航的“素材／词典”切换直接占据侧栏头部，不再与重复标题上下排列。

创作、素材、词典、搜索及复用共享适配器的集合侧栏使用同一头部与窄轨；主体内的嵌套集合不注册到外层头部。分屏各有自己的顶行，原有窗格折叠与保存保护保持独立。本文不把窗格收起视为仅收起标签标题，也不把视觉改动视为侧栏全局共享。

`WorkspaceTabItem` 使用内容类型图标、可聚焦的完整标题提示、预留关闭槽位和独立加载图标。按后续反馈去掉页签顶部强调线：活动窗格普通标签为 500、当前页为 600；非活动窗格全部为 400，并保留自己的选中轮廓。状态复用原有 `active`，键盘焦点仍有独立轮廓，菜单、键盘、中键关闭和跨窗格移动沿用原行为。横向滚动和全部标签菜单仍沿现有实现；搜索、重名消歧、误关恢复、固定与拖拽未在本批新增。

选中页签采用已选 C 曲线。`WorkspaceTabShape` 由两个固定宽度的镜像 SVG 端部与可伸缩中段组成，保留平顶、轻斜边和底部外展；沿现有主题绘制单条边界，不使用整张 SVG 的横向缩放改变曲率。装饰层禁用指针事件并从无障碍树隐藏，按钮维持独立焦点与点击区域。展开态标签条两端预留外展空间，标签滚动边距同时考虑曲线和关闭按钮；收起窄轨不套用曲线。轮廓绘制不需要 DOM 测量或额外的共享样式变量。

## 工作区切换动效

`WorkspaceTabShape` 的装饰层在展开态保持挂载，通过选中状态和 Tailwind 的透明度过渡呈现、隐去曲线，复用 `motion-fast` 与 `ease-standard`。隐藏装饰不接收指针事件，也不进入无障碍树；收起窄轨沿用颜色过渡。

`AppWorkspaceGroup` 切换可见会话时直接显示工作面。同类侧栏宽度不同时，`WorkspaceSidebarMotion` 同步过渡头部与内容边界；目标没有同类侧栏时仅原侧栏淡出。原来的整页 `workspace-tab-reveal` 不恢复，标签轮廓的局部反馈保留。

没有移动或复制编辑器，不合并标签状态，也不改变原有 `hidden`、`inert`、portal 目标、会话挂载上限、保存保护和导航提交时机。共享集合侧栏的收展与直接调宽分开处理，接入范围和未验证项见[工作区动效实现](workspace-motion.md)。不能据此认为创作页全部面板、大纲和图片预览已接入新动效。

## 页面与面板

`components/ui/tab-styles.ts` 维护细线选中外观。`TabsList` 提供普通与紧凑密度，`Segmented` 的 `appearance="line"` 复用同一视觉；Tabs 的内容面板关系与 Segmented 的值选择语义分别保留。

`CodexArtifactsScreen` 的页内导航与任务历史、用量侧栏共享 Grid 列；侧栏跨越导航行和内容行，导航只占主体列。组件内的关系选择器与 `subgrid` 沿用侧栏实际宽度，不增加独立偏移测量，也不移动导航 DOM。窄布局将侧栏放回内容行，恢复按钮复用导航条的 portal 容器。历史与用量通过 `Activity` 保留已访问状态，隐藏栏目释放头部注册，避免争用同一个工作区头部。此布局仍需实际窗口缩放、拖动和键盘焦点的 UI 验收。

基础 Tabs 消费者共享字号与状态；AI 中心、扩展中心移除各自的标签高度覆盖，素材检查器采用紧凑密度。素材／词典切换和创作产出模式采用细线外观。产出区有空间时显示短名称，窄栏保留图标和键盘可达提示；内容辅助面板按可用宽度显示名称或整组仅图标，收起窄轨使用图标，方向与明确激活由原 Tabs 管理。语言、布局及筛选仍为分段选项。

`ContentWorkspacePanelNavigation` 在面板操作之外测量标签可用宽度，以不参与交互的隐藏行测量当前语言的完整标签，并按选中字重预留空间。`ResizeObserver` 同时观察可用宽度与测量行，覆盖拖动、分栏、字体和语言变化；恢复文字前预留 8px，避免临界宽度反复切换。布局变化复用原标签按钮，保留提示、无障碍名称与选中状态；隐藏测量行不进入无障碍树。极窄时保留图标横向滚动作为访问兜底，并明确关闭标签栏纵向滚动。

新外观沿现有主题、i18n 与减少动态效果设置；未增加主题、持久化字段、版本或依赖。
