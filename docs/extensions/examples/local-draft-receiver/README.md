# 本地草稿接收器

这个示例使用既有 `article-draft-delivery` HOST 适配器，不增加可执行插件运行时。`plugin/manifest.json` 可以通过扩展中心安装；旁边的 `receiver.mjs` 是作者明确启动的本地开发工具，不会被插件安装器复制或执行。

需要扩展宿主 0.3.10 或兼容版本。状态接口声明 `capabilities.documentModes: ["draft"]`，正文请求和成功响应均带 `mode: "draft"`；缺少明确模式的请求会拒绝。这个版本与应用版本独立，完整协议及图片处理见[文章投递](../../../article-delivery.md)。

## 走一遍真实交接

在仓库根目录执行 `node docs/extensions/examples/local-draft-receiver/receiver.mjs`。它只监听 `127.0.0.1:47839`，终端给出一次随机令牌；不调用模型、不联网到外部服务、不读写资料库。停止进程后丢弃全部示例草稿。

在扩展中心安装本目录的 `plugin` 子目录。打开“权限”，检查准确回环地址和此示例专用凭据用途，分别授权并启用。回到“设置”，填入终端令牌并检查连接。使用已保存的纯文字图文，选择此渠道上传草稿。

只支持无图片、无封面、无媒体绑定的纯文字图文。每个请求不超过 600,000 字节，Markdown 不超过 512,000 字节；最多保留 20 份不同请求，超限明确失败。相同请求和幂等键重复提交返回同一回执，进程重启不保留幂等记录。

回执只是本地接收确认，不是公开发表。`adminUrl`／`publicUrl` 为满足现有交付协议而返回的本地标识；示例不提供可浏览的正文页面。不要将它当作网站部署、备份或长期保存工具。

撤销网络或凭据权限后重新尝试，不应再产生新的请求。宿主在各次上传前重新检查权限和连接；已经发出的请求不能收回，超时或响应丢失也不证明远端未收到。

## 调试

连接失败先检查进程、端口及临时令牌，别重新开放任意 origin。安装取消、拒绝授权、重复发送、服务停止与正文超限均应有明确结果。收到 415 是这个示例拒绝媒体，不是静默跳过图片。

需要调整端口时，同时修改 manifest 的 endpoint 与对应精确网络权限，并重新检查授权；仅改终端服务端口不会扩大旧授权。测试使用随机端口和合成正文，不能把个人令牌写进仓库或验收工件。

交互示例在 `npm run design:dev` 的 `/extensions.html`；它复用真实权限面板及插件列表，但仅修改内存中的演示数据，故意与上面的实际插件安装和 HTTP 接收器分开。
