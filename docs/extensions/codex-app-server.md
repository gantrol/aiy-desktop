# 统一 Codex 插件

`com.aiy.codex-app-server` 是 AIY 内置的统一 Codex 能力身份。任务历史、用量调查、生成图片、可视化发现、Codex 连接和内容引用都在同一个插件工作台中呈现，不再作为多个面向用户的插件分别安装。

该插件的 manifest 由宿主在 [`src/main/extensions/builtin-manifests.ts`](../../src/main/extensions/builtin-manifests.ts) 注册。`extensions/com.aiy.codex-history-search/`、`extensions/com.aiy.codex-image-discovery/`、`extensions/com.aiy.codex-usage-investigator/` 和 `extensions/com.aiy.codex-visualization-discovery/` 只保留旧安装状态与授权迁移所需的稳定身份；包扫描会忽略这些旧 ID。不要把其中任一目录当作当前插件入口或另行发布。

## 责任边界

| 宿主共同负责                     | Codex 插件负责                       |
| -------------------------------- | ------------------------------------ |
| 扩展启停、授权、兼容和错误隔离   | Codex 连接状态及其专用设置           |
| 内容身份、资料库写入与用户确认   | 任务历史的只读投影与搜索             |
| 文件选择、导出目标与安全路径校验 | Codex 图片和可视化的发现、预览与导入 |
| 统一语言资源、焦点和应用导航规则 | 用量扫描、报告、明细与统计对比       |

插件停用后不再发起新的 Codex 操作。已经进入资料库的内容仍由宿主管理；插件索引、报告缓存和连接状态不能冒充用户作品。

## 工作台

用户只看到一个 Codex 插件。功能页内部按任务历史、素材、用量和设置组织：

- 任务历史读取本地 Codex 任务投影，并在明确选择单个任务后读取详情。
- 素材合并生成图片与可视化发现，不把同一来源拆成多个安装项。
- 用量调查读取本地记录及获准的额度快照，生成可保存的只读报告。
- 设置管理连接、模型、保存目标和可选权限；它不复制各功能页的结果。

## 用量调查

用量页按“一览、查明细、自行对比”组织同一份报告：

- 一览显示 API 等值或已计价小计、模型额度历史观测、整轮等待和记录缺口。
- 明细分别列出计价覆盖、缺值、额度池与窗口、排除记录以及已保留完成轮次。
- 自行对比允许选择模型、模式、思考强度、指标和阈值，并查看逐轮点、阈值内比例或分位数曲线。

模型额度观测使用报告所选时间范围内的本地 Token 与额度历史记录，不读取或展示当前余额。总览和额度明细提供“采样跨度”选择：1%、3%、5%、10%，新报告默认 3%。选择随当前报告保存，切换时只从本地索引重算额度观测，不重新扫描原始日志；计算期间禁用跨度选择和报告导出，失败保留原结果。总览、明细和导出使用同一跨度，返回报告时恢复已保存的选择。

先按套餐、额度池、窗口隔离，再按分钟合并并发额度观测；同一连续区间累计达到所选跨度后形成样本，超过跨度时保留实际差值，不拆成虚构的整百分点样本。未达到门槛的尾段不外推。只比较单一模型与模式，混合使用、重置、过期观测和缺失记录不混入样本。

主指标为“Token / 1% 额度”。每个观测点对应一个完整区间，以该区间记录的 Token 总和除以实际观测额度百分点；总 Token 包含缓存输入，也可选择“非缓存输入 + 输出 Token / 1%”。额度观测不计算估算 Credits。图表按样本完成顺序等距排列，不再按小时、天或周合并；表格显示观测序号、结束时间、缓存占比、请求数和实际跨度，悬停时间或图点可查看起止时间。相邻有效样本可以跨时间间隔比较，连线不代表中间记录完整。明细图表与表格同步分页，每页 50 个样本，总览保留最近 16 个样本。

算法版本 2 记录所选最低跨度；旧报告按算法版本从本地索引补算并保存，不重新扫描源文件。读取旧报告时移除额度观测样本的估算 Credits 和缺价计数，保留 Token 与采样跨度。CSV 额度观测样本只导出 Token、实际额度变化及最低采样跨度等观测字段，JSON 导出版本为 15。界面标为“本机观测”：Token 来自本机可读日志，额度为账户共用，其他设备或云端并行使用会压低比值；没有全账户日志时覆盖范围未知，不猜测补偿。采样跨度越小，越容易受取整影响，各种跨度仍有上报误差。这个比值可用于观察额度效率变化，不能单独证明模型被替换或能力下降。

这些结果遵守以下口径：

- API 等值是按公开费率重估的情景值，不是账单或实际支出。
- Credits 折算差额不是订阅额度节省；不同额度池和窗口不合并外推满额容量。
- Standard 与 Fast 的整轮耗时中位数之比只是未配对观察，不是 Token 生成倍速或因果效果。
- 完成轮次不表示任务验收成功，日志也不能认证实际服务模型或给模型质量打分。
- 缺值不填零。报告样本被截断时，无法确定的未保留数量显示为未知。
- 图形可以有界缩减绘点，但统计、阈值计数和导出继续使用全部已保留的有效值。

对比方案只保存查看条件；导出的冻结结果另带报告范围、价格依据、数值样本和限制。导出白名单不包含提示词、回复、工作目录或本机路径，但时间戳和模型名仍属于可识别元数据，必须在用户主动导出时处理。
