# 创作输入的分屏归属与保存

图集浏览曾从启动数据中的最近草稿取得编辑身份。另一分屏更新该草稿后，图集导航会先提交旧快照，被数据库的版本校验拒绝。这是页面归属与保存生命周期错配，不能通过放宽版本校验解决。

## 入口与编辑归属

`creatorInitialSession` 仅在默认入口选择最近的独立草稿或创作。明确对象入口按自己的 ID 恢复；构思记录也通过来源草稿 ID 加载，不使用全局最近草稿代替。文章配图仍按已有派生关系恢复。

恢复标签或历史位置时，草稿读取成功才确认位置已应用。读取失败保留当前编辑内容，并将失效位置替换为当前工作面的位置；启动时没有输入会话则回到新建页，不自动载入另一份最近草稿。已删除或已消费草稿返回 `CREATION_DRAFT_UNAVAILABLE`，界面沿语言资源提示；过期请求不能改写后来选择的位置。

新标签按明确草稿 ID 初始化时，若本标签尚无输入、草稿身份或已选作品，直接向初始空编辑器恢复草稿，避免先重置会话再创建一次编辑器。已有输入的切换仍执行保全与会话替换；读取期间产生的输入也必须先保存。

作品树与草稿列表的更新分开：草稿加载、保存通知和选中变化只更新草稿区域，不重绘整棵作品树。只有多个形态的作品条目建立折叠状态和吸顶路径登记，单个形态仍保留原有打开、拖动和菜单操作。

`creatorInputOwner` 统一判断当前内容是否拥有创作输入。图集、评测、图片拆解与非配图状态的图文页不拥有该输入；独立创作与灵感输入保留编辑身份。渲染、输入活动状态、导航保护、恢复和助手作用域共用这一判断。灵感输入沿用显式保全流程，不因此开启自动草稿保存。

分屏可见、拥有键盘焦点与拥有编辑会话是不同条件。两屏都可独立编辑；素材撤销快捷键只接收所属窗格的事件。隐藏状态的缓存不能让浏览页成为旧草稿的写入者。

## 新创作的任务与正文

普通新建先自动暂存，可直接输入标题和内容。既有 `manuscript` 草稿模式继续承载自由文字，并不表示已建立正式文章。正文末尾通过 `NewCreationDirections` 展示五个等权方向，按自身容器宽度排列为五、三、二或一列；输入、自动保存与材料导入不收起方向。图文和大纲标为“将输入存为图文／大纲”，明确沿现有流程保存并进入编辑；图片、动图和视频整理用带省略号的动作标签表示进入准备工作面，选择入口本身不请求模型。已有图文／大纲中的“准备新产出…”先回到带作品来源的独立输入，再选择制作方向。默认没有选中正式产出方向，也不显示“继续编辑图文”或“暂存当前输入”。空白输入也可明确开始。

`NewCreationOutputWorkspace` 在自由输入会话中初始收起产出栏，主动打开后只显示已有作品、适用来源或“暂无产出”，不重复展开五个创建动作。侧栏状态按输入会话与任务重建，不重建正文；起步页的收展不覆盖制作工作面的持久化偏好。进入正式图文／大纲或专用制作工作面后，正文五格不再挂载，新增沿产出栏和各工作面既有入口继续。图片与视频准备面的产出栏复用 `NewCreationDirections` 列表布局，零至六份作品时创建组默认展开，更多时默认折叠。已有作品先按实际标题列出，并显示“打开／编辑中”。

产出、目录、媒体、附件和评论共用同一个侧面板宽度；底部布局共用一个高度，切换标签不重新载入各自尺寸。旧图文偏好按最后活动标签的宽度归并，后续只写共享宽度；通用面板按工作面保存共享尺寸，并只在首次读取时接收旧活动标签的尺寸。图文与大纲复用同一窗格偏好。标签及收展、缩放控件在同一行内居中排列，窄侧栏的标签区可横向滚动。

`CreationDocumentStarter` 采用单栏纸面，标题输入保留但无占位文字，标题与正文对齐。`CreationDocumentToolbar` 复用共享格式按钮与菜单，随正文滚动吸顶；素材选集在工具栏按需打开，正文不再常驻重复缩略图。正文图片完整显示并限制预览高度，不修改保存尺寸。输入法、图片导入、撤销与文档捕获继续由共享编辑器承担；工具栏接收同一编辑器实例，收展浮层不重建正文。图片参数只在图片工作面出现。

草稿的 `startMode` 和正文一起保存、恢复、比较和另存，不再用全局偏好决定所有草稿的工作面。存储在原提示节点 JSON 的第三版封装中；旧数组及第二版文档继续可读，无模式的旧草稿回到图片提示词界面。保存请求未提供模式时保留原值。普通新建显式请求图文，不把图集的图片配方注入正文；明确制作图片时仍应用该图集的配方。

切换到图片或视频任务先保全当前会话，再建立独立草稿。`creationDraftStart` 接收可选参考图片 ID、视频材料 ID 和明确的创作来源，复用原保存事务校验并持久化选集，旧调用仍可空白起步。图片方向仅带参考图，视频方向仅带视频；动图入口把参考图交给现有制作工作面，沿原格式核验准备帧。导入中暂缓方向切换，输入结算后从当前会话捕获选集。当前正文不自动成为图片或动作提示词，原稿继续保留。选择大纲沿现有明确转换流程生成大纲。关联归属见下节。

视频准备面复用已附视频的材料身份，与图库来源共用播放器及创建动作，不把附件拼成伪造图库条目。进入时只有一段可预选，多段必须明确选择；清除来源不清空选集，移除附件只修改当前草稿，不删除素材或原稿。视频准备组件随输入会话更换，避免上一草稿的来源选择串入新稿。此处只创建视频文档，不自动调用转写或成文。

材料选择保留参考用途；参考缩略图的“插入正文”通过编辑器事务插入图片。粘贴图片同样进入正文。图文转入正式文章时，只将正文实际使用的图片写入文章媒体绑定，参考选集保留在创作输入中，不全部追加进正文。旧提示词草稿的转换行为保持原义。

图文首屏的 AI 辅助使用选段浮层：完成文字选择后显示“改写选段”，点击才捕获改写基准并聚焦要求输入；空稿或无选区从工具栏进入写初稿／列大纲。选段检查与请求捕获复用 `documentWritingSelection`，排除图片和其他原子节点；选中本身不读取候选历史或执行请求。`DocumentWritingPanel` 在浮层关闭后仍保持写作会话，候选按原草稿归属保存，输入框、候选预览与显式采用仅在展开时显示。独立的 `writingInstruction` 随当前草稿自动保存，存于已有 JSON v3 输入封装；旧数组／v2 数据仍可读取，旧调用省略要求时保留存量值，显式空字符串才清空。正文不兼任这份要求，也不进入图片提示词优化。

## 同一创作的多份产出

`creationSource` 区分来源输入 `DRAFT` 与已有产出 `FORM`。新任务从输入接续时，主进程将它解析到已有产出来源或最初的输入身份，避免无限串接草稿。来源保存在现有 v3 JSON 封装，后续保存由主进程保留；普通正文保存不能任意更改归属。旧输入没有来源字段时，以自身身份作为这一轮工作的起点。

`creation-continuation` 在各产出的写事务内登记归属。来源是已有产出时，新增形式加入同一创作项并保存 `sourceFormId`。来源尚为输入时，用根输入 ID 的固定摘要取得候选创作项 ID，仅在首次产生真实内容时建立创作项；其他任务产出加入此项，不在浏览空模式时建立空作品。删除或归档的创作项不能因新产出被悄悄重建。

接入图文／大纲、图片执行及图片导入、动图和视频整理创建。各自保留现有内容身份和保存方式，原输入是否消费沿原操作含义；从自由输入另开动图／视频不会消费自由正文。视频整理以任务草稿与视频材料确定重试身份，同一任务重复提交返回已有结果，另一任务可围绕同一视频另做整理。无明确来源的旧视频入口继续沿原有复用逻辑。

同项导航复用 `useCreationWorks` 投影已有作品索引，不逐份加载正文。新创作、图文和大纲通过 `CreationOutputsPanel` 展示准确作品、当前选择、同名区分和来源返回；作品较多时提供局部标题查找。图文和大纲的“新增产出”先保全当前会话，再进入带来源的暂存输入，由该输入选择正式类型；不自动复制原稿内容或运行模型。专门的图片、动图、视频工作面继续使用相关内容菜单，动图沿自己的保存会话切换。草稿从服务端获得所属创作项 ID，因此重开输入后仍能找到已产生的同项内容。不迁移既有子创作关系或新增主题实体。

产出栏与图文的目录、媒体、附件、评论共用辅助空间；大纲沿同一辅助区切换产出和评论。没有保存的图文布局偏好且具有创作上下文时优先选择产出，已有面板及显隐偏好保留。新创作单独记住收展，内容区达到 768px 时并排，更窄时沿共享工作区的底部折叠面板；图文继续使用既有布局阈值。收展、调整宽度和最大化不重新挂载编辑器；隐藏内容不读取全部作品正文。窄屏侧抽屉与完整主题级输入返回仍属于后续设计，本批不以底部面板冒充抽屉。已转换草稿的消费规则不变，失去编辑身份的起步输入不伪装成可继续的正式稿。

## 图文的正文与媒体布局

图文工具栏不再提供“正文／媒体”切换。媒体通过辅助栏打开，复用 `ArticleMediaPanel` 与可控展开的 `ContentWorkspacePanels`；正文编辑器仍挂载在原会话内。辅助栏展开与最大化不复制文档、内容身份或撤销历史，返回正文恢复同一滚动容器；从媒体定位图片会先恢复正文。开启图文内部双编辑窗格时恢复正文。`ContentViewMenu` 保留图标与下拉箭头，名称通过提示和无障碍标签提供。

图片排序、移除使用、封面和定位继续沿原操作。每个正文图片位置可编辑替代文本，缩略图下展示已有替代文本；这不是新增独立图注字段。变更按元素身份及原替代文本核验，以编辑器事务保存、撤销。图片被移除或原值已变时保留对话框输入，不改动别的位置。只作附件、尚未放入正文的图片仍沿附件／媒体绑定管理。

## 写作候选

`DocumentWritingPanel` 复用现有 Codex 对话执行及任务记录，按当前输入会话隔离面板状态。`documentTask` 固定操作、原正文及适用选段，`message` 单独承载要求；仅在点击生成后执行。首批只处理正文文字，不发送参考图片、视频或整个材料集合；输入沿现有 30,000 字符限制，候选上限为 10,000 字符。独立写作模型选择、读取外部文档与从来源摘录发起仍未接通。

写作使用独立执行分支与本次输入，不继承图片对话的隐藏历史；生成的 Markdown 存于这次带 `documentTask` 的记录中，不再包装成优化后的图片提示词。普通图片对话的后续请求不自动引入写作候选。后台超时、取消、失败与中断继续沿现有执行层管理；本轮没有新增服务商客户端。

候选可查看本次输入、替换正文／原选段或追加到正文。采用前先保全当前输入；替换重新核对完整正文基准和选段文字，正文已变则保留候选，只允许明确追加或重新生成。采用通过普通编辑器事务进入撤销历史，不回填标题。Markdown 候选拒绝新媒体、原始 HTML 及 AIY 动态引用，预览不加载模型编造的外部图片。

面板展开才分页读取当前草稿的候选；关闭不取消任务。切换输入会话后忽略过期界面回执，结果继续由原作用域记录。原草稿已经转成正式图文时，写作结果仍可存入原草稿的任务记录，不自动覆盖正式图文；接回正式稿的采用入口属于后续范围。作用域被明确删除或执行失败时，继续由原任务记录报告失败。

## 保存生命周期

`useCreationDraftSession` 管理一份输入会话的草稿身份、版本基准及确认快照；`useCreationDraftSaveQueue` 保持同一实例内的写入顺序。输入法与图片持久化完成后才捕获可保存输入。会话替换、离开或采用其他输入使过期操作失效，旧回执不能替换新会话。

载入与确认保存都建立相同字段的快照键，未改变的输入不重复调用保存。重新打开同一草稿时，只有确认时间更新的本地回执才可替代读取结果，旧缓存不能倒灌。修改标题等尚未取得完整新回执的变化仍需正常保存。

存储层仍用 `expectedUpdatedAt` 拒绝旧版本写入。`CREATION_DRAFT_CONFLICT` 是穿过 Electron 错误包装的稳定标识，界面文案来自语言资源。队列失败保留原版本链，不能把其他分屏的更新默认为本屏修改的保存基准。

## 冲突恢复

`useCreationDraftConflict` 把版本冲突记录在发生错误的会话中；已知冲突后，继续输入不反复提交旧基准。`CreationDraftConflictStatus` 在当前输入区域提供操作，不阻塞另一分屏，也不重复发送原始 IPC 错误通知。

- 对比按该草稿 ID 读取已保存版本，显示两份标题、文本和素材数量。预览不等于完整文档结构与生成设置的差异工具。
- 另存通过同一保存队列写入无原 ID 的完整快照，包括文档、图片、视频、词条、配方和生成配置。成功后切换为新草稿身份，并直接更新本标签位置；无需再次读取和覆盖输入，保存期间的后续输入继续留在新会话。原草稿保持不变。
- 替换输入必须先取得可查看的版本。再次读取期间若本屏输入或已保存修订变化，保留当前输入并要求重新核对。只有显式替换动作才装载保存内容。
- 读取、保存失败或会话已切换时，保留输入或忽略过期结果。恢复后不自动执行早先被拒绝的导航。

## 离开边界

页面内选择内容通过 `preserveBeforeNavigation` 保全实际编辑输入。`useCreatorNavigationProtection` 把同一保全入口注册到本标签的历史／关闭保护，以及整个工作区的退出 drain。单屏导航只检查被替换的标签；应用退出由工作区汇集相关会话的结果。保存失败不执行离开回调。

当前实现没有把创作输入草稿改成跨标签实时共享正文，也没有修改文章和大纲的共享编辑协议。实现核对与产品规则分别维护；详细测试及运行记录归私有测试仓。
