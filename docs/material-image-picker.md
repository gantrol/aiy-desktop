# 素材选择器

`MaterialImagePickerDialog` 负责素材选择草稿，供新创作、动图及过渡图片入口共用。新创作文稿工具栏的“素材”直接打开弹窗，不再先展开图片／视频二次入口。文稿入口同时接受图片和视频；动图、图片模型参考及过渡图片入口继续只接受图片。搜索、分页和集合导航共享已有素材查询；确认时才把有序清单交回发起者，取消不改原选择。

文稿入口的本地导入允许同批选择图片和视频，分别复用已有图片参考导入和视频收录流程。确认选集后，图片写入参考列表，视频写入视频附件，各自最多 8 项；两类的相对顺序分别保存，不新增跨类型顺序字段。素材计数包含两类附件；原有图片插入正文和视频转文稿动作继续保留。

## 分屏与焦点

选择器通过 `WorkspacePaneScope` 的容器和现有 `Dialog` 承接分屏内弹层。所属窗格低于 40rem 时铺满，高于该宽度保留每边 0.75rem 外边距；窗口级回退沿用普通弹窗。命名容器查询依赖所属窗格，素材网格直接根据结果区宽度自动排布。

图集导航继续使用 `WorkbenchNavigationPane` 的容器测量与偏好隔离。窄时从标题栏展开导航，选择后回到素材；改变宽度不覆盖原有收展偏好。另一分屏继续可用，点击外部不清掉当前待选项，Escape 只由焦点所在的分屏处理。

打开时焦点进入搜索，关闭后返回原触发位置。已选缩略图可拖动排序，也支持聚焦后按 Alt + 左右方向键调整顺序；数量、导入、取消与确认动作位于固定底部。

## 查询与选择

`MaterialImagePickerToolbar` 承接输入法组合、清空和当前范围标签；组合结束后提交查询。`useMaterialImagePickerMaterials` 将关键词加入请求身份，并传给 `galleryList` 的首页和后续游标请求。非空搜索延迟 200ms，查询变更或关闭时取消尚未发出的请求，已发出的旧响应通过请求身份失效。

名称检索沿图库现有实现：素材显示名或原文件名、关联创作标题、词条标题，以及已有来源与格式字段。不会仅筛选当前已加载的缩略图，也不扩展到 OCR 或视觉语义搜索。切换图集或词典范围保留关键词。

新查询返回前隐藏旧候选；失败保留输入与待选清单，可重试当前查询。候选类型由宿主的 `includeVideos` 决定，并纳入查询身份；如果当前页没有兼容项但存在后续游标，保留继续加载入口，不提前显示无匹配。图库列表通过现有视频元数据的一次关联查询返回可选时长字段，不逐项查询。视频候选显示时长，播放入口独立于选取动作；缺少素材身份或有效时长的视频不可加入草稿。

已选清单独立于候选页。开始搜索后继续添加素材，会追加到现有有序清单；重新查询不会重排之前的选择。未改变范围的初次多选仍保留原有集合顺序规则，兼顾动图等按来源顺序选帧的入口。候选只加载缩略图，用户明确打开视频预览后才允许播放原件。

本地导入沿用关闭选择器后直接导入当前目标的行为，不保留关闭前尚未应用的临时选集；导入后的材料仍保存在库中。选择器内导入后继续维护同一份待选草稿尚未实现。

中英文文案由 `gallery.imagePicker` 语言资源提供。数据契约、迁移、插件版本和应用版本保持原有值。
