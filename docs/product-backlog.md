## 低优先级：图库品牌配图与关联关系

状态：仅记录，当前不实现。

图库可考虑拥有自己的切换配图。后续设计前需先确定：

- 配图归图库所有，还是引用图库内的一项素材；其删除、替换和缺失状态如何处理。
- 源图库商标、目标图库商标和图库配图如何随切换事件一起提供。
- 配图缺失时只按现有商标动画运行，不为组合差异增加兼容分支。

建议按可用资产自动选择动画编排：

| 可用资产               | 动画编排                            |
| ---------------------- | ----------------------------------- |
| 源商标、配图、目标商标 | 商标 1 → 配图 → 商标 2              |
| 源商标、配图           | 商标 1 → 配图，并由配图衔接目标界面 |
| 配图、目标商标         | 配图先展开 → 商标 2 落位 → 目标界面 |

交互原则：编排跟随真实切换进度，不为完整播放动画增加等待时间。
