# 本地图片编辑

共同交互见 [图片编辑](https://github.com/gantrol/aiy-docs/blob/main/design/pages/image-editing.md)。本文记录 2026-10-03 工作树的首批实现，不表示已发行或完成原生界面验收。

## 当前入口

临时 PNG／JPEG 贴图的工具区和菜单提供“编辑图片”，在同一窗口展开。支持自由裁切和像素尺寸输入、箭头、矩形、文字、实色遮挡；更多菜单提供编号、矩形高亮、手绘、90° 旋转和翻转。对象可再次选中、移动、改参数、复制、删除和调整前后顺序，重叠对象可从选择列表定位。裁切与矩形有角控制柄，箭头有端点控制柄。

截图插件的选区工具栏可直接选择“编辑图片”：仅将选区保全为独立临时 PNG，在贴图窗口打开本编辑器，不同时复制或写入剪贴板历史。完成后回到该贴图，暂不返回原截图选区。截图会话与失败重试见[截图插件](clipboard-capture.md#capture-and-adoption)。

画布提供原图对照、适应、100% 和缩放；放大后的内容通过滚动区查看。编辑拖动与移动窗口分开。方向键按图像像素微调，Shift 使用十像素步长；Ctrl／Command + Z 撤销，Shift + Ctrl／Command + Z 重做，文字和数值输入优先接收按键。窗口仍可置顶、调整尺寸、收起和隐藏。

完成采用当前结果并回到贴图；完成并复制、完成并转为图文先采用，再执行后续动作。复制失败保留已采用结果，重试不重复生成版本。转换将当前结果作为正文图片并留下继续输入的位置，不改变临时身份。取消修改清除未完成工作稿并回到上次采用版本；收起／隐藏请求落盘检查点，不等同于取消。

## 保存与边界

`shared/contracts/image-edit.ts` 定义版本 1 的裁切、方向和标注结构。坐标以经过 EXIF 方向解释的原图像素为基准；显示和输出共用几何变换，窗口尺寸和查看缩放不参与结果尺寸。图片采用后输出 PNG；SVG 选框、控制柄和恢复信息不会进入输出像素。

`renderer/features/image-editing/` 分别负责画布交互、工具／参数、几何与导出、会话队列和保存接续。编辑器通过现有 desktop-petals 通道调用主进程；发送窗口决定临时文件身份，不能由 renderer 指定另一文件。原图通过现有受限媒体协议读取。

`main/temporary-files/temporary-image-edit.ts` 在临时存储队列中核对版本和请求身份。正文记录独立保存原图身份、当前结果身份、已采用结构及未完成工作稿。采用先保全输出附件，再提交引用和编辑结构；只有成功后才移除过期的派生图片，原图始终保留。请求丢失回执时沿同一身份重试；明确的容量拒绝允许取消或继续改稿。编辑检查点、采用、退出保存串行执行，退出期间冻结修改，输入法组合尚未结束时阻止退出。

撤销／重做保留本次会话最近 20 个步骤；重启恢复当前工作稿和已采用版本，不恢复整段撤销历史。检查点约在一次动作结束后 700 ms 写入；退出会请求立即保存。检查点仅证明已落盘的输入，进程强制终止前尚未确认的最后动作不保证恢复。

首批限制为静态 PNG／JPEG、单文件 25 MiB、单边 16384 像素、总计 3200 万像素。沿已有图片识别逻辑读取 EXIF 并拒绝 APNG；最多 300 个标注，单条手绘 2000 点、合计 12000 点。导出 PNG 不超过 25 MiB。临时容量不足时保留原图和工作稿，采用失败可重试或取消；编辑内容受保护，不自动转常驻或作为容量回收候选。

转常驻先要求采用成功，再迁移实际使用的结果。原图字节和编辑记录保存在目标空间 `image-edits/<临时内容 UUID>/`，原图不额外创建图库条目；记录在临时文件清除前确认。此归档目前用于保全，普通库内贴图／正文尚无读取它继续编辑的入口，也尚无单独整理归档的界面。修改图文附件和正文时保留同一份编辑记录。

## 本机敏感检查

2026-10-06 补充：临时 PNG／JPEG 的编辑器在“更多工具 → 本机敏感检查”中提供 Windows 系统 OCR 与规则识别。可选择邮箱、电话号码、常见凭据格式和指定词；指定词每行一个，最多 30 个、每个 100 字符，只保留在当前编辑会话。当前范围不是姓名／地址实体识别或业务机密语义判断，也不包含生成式 AI 改图。

检查输入固定为当前裁切、旋转、翻转和标注合成后的 PNG。候选以黑色实色遮挡预览在同一画布，支持逐项取消；采用后加入原有可编辑标注，整批只占一次撤销，之后仍可移动、调整或删除。候选未采用时阻止完成／复制，关闭检查即丢弃候选；采用后的完成、复制和转图文继续沿原有保存协议。无匹配只显示“未发现匹配项，请核对遗漏”，不产生“安全可公开”状态。

`shared/contracts/image-privacy.ts` 约束任务参数和结果；preload 只提供检查／取消接口，主进程沿花瓣发送者校验并限制为当前临时图片窗口。`main/image-privacy/` 负责单任务限流、原生识别和规则定位；OCR 在无窗口辅助进程执行，以 stdin 接收图片，图片与识别文字不写临时文件、不记录日志、不调用模型或网络接口。renderer 只收到类型和矩形范围，原始识别文字不进入编辑记录或搜索索引。

原生识别使用系统已有语言，缺少识别器、超出系统尺寸上限、超时或不支持的平台分别返回短状态，不下载组件、不自动改用云端，也不缩小图片掩盖尺寸限制。输入最多 25 MiB／3200 万像素，返回最多 300 个候选；超过剩余标注容量时整次拒绝采用，不静默截断。全应用最多一个检查，超时为 30 秒；取消、窗口隐藏／关闭、renderer 退出或导航释放辅助进程。编辑修订变化使候选失效，迟到结果不进入新稿。矩形按系统 OCR 的文字角度修正，再逆变换回原图坐标；覆盖完整识别词并向外留边，识别遗漏仍需人工补选。[OCR 返回结构](https://learn.microsoft.com/en-us/uwp/api/windows.media.ocr.ocrengine?view=winrt-26100)、[文字角度定义](https://learn.microsoft.com/en-us/uwp/api/windows.media.ocr.ocrresult.textangle?view=winrt-26100)。

相关既有组件与集成回归、类型、格式／lint 和生产构建通过；单元回归存在与本轮未修改的花瓣设置尺寸有关的失败。现有合成图片只验证系统 OCR 可返回结果，未验证识别准确率、真实图片像素覆盖、混合语言、旋转截图或原生界面交互。未新增测试代码、修改快照或进行 UI 手动测试；本批尚未提交或发行。

## 后续边界与验证

普通库内图片、正文图片的编辑入口仍待接入；它们需要各自的采用位置、基准版本和返回责任，不能直接用临时身份代替。截图已通过独立临时图片进入编辑，但返回截图结果和插入原正文位置尚未接入。裁切比例锁定、拖动边、文字框自动换行、可调高亮强度、输出格式／压缩／尺寸选择也未接入。图片文字检索由[搜索工作面](image-search.md)独立复用系统 OCR，按活动资产保存派生索引；本机敏感检查仍只产生候选遮挡，不将检查结果送入该索引。快捷键设置沿独立命令设计处理，不在编辑器中注册系统截图热键。

本批使用现有相关单元、组件、集成测试，并执行类型、静态和生产构建检查。没有新增测试代码或触发 UI 手动测试；现有回归检查不等同于新画布行为的专项覆盖。实际指针裁切、系统缩放、输入法、剪贴板像素、重启恢复、转常驻归档和窗口最小尺寸仍未进行原生交互验收，也没有性能改善结论。
