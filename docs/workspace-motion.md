# 工作区动效实现

共同规则见[动效与视觉锚点](https://github.com/gantrol/aiy-docs/blob/e41e6ffd89e21a8010213ba3418a30f99c76eaaf/design/interactions/motion.md)，配套为 [aiy-docs PR #31](https://github.com/gantrol/aiy-docs/pull/31)。本页只记录桌面接入与限制，不复制共同规则。

## 集合侧栏统一

2026-10-07，在 `6dbddef7b3280d27ca4bc49ba296e62327c4e756` 基础上统一创作库与共享集合侧栏。`WorkbenchSidebarHeader` 负责 36px 头部、52px 收展槽位和两端对称留白；创作新建图标恢复居中。`WorkbenchSidebar` 为列表／详情和导航适配器提供相同背景、边界、窄轨和顶部入口。各页面的安装、刷新、搜索等动作仍由原宿主提供。

`WorkspaceHeader` 保留每个标签的侧栏几何登记，但工作区标签独占完整一行。顶层集合侧栏的头部留在下方本地侧栏；`WorkspaceSidebarContent` 标记主体内的嵌套集合，避免其宽度覆盖外层侧栏。

`WorkspaceSidebarMotion` 在每个分屏中协调一个 `--workspace-sidebar-width`，创作网格与共享侧栏读取同一个插值宽度；标签条不读取该变量。该注册属性及退出关键帧保存在组件目录，不进入共享 token。明确收展和导航后的宽度差异使用 180ms；拖动、键盘调宽及容器尺寸变化直接接管几何。每个标签仍分别保存自己的宽度与收展状态。

控制栏大类或标签切换前，容器只采集包含本地头部的原侧栏装饰副本；提交后目标没有同类侧栏才保留 120ms 淡出。副本移除 ID，整体 inert、隐藏于读屏且不接收指针，不挂载第二份 React 树、编辑器或读取会话。滚动位置仅用于维持退出画面；后续导航、目标侧栏出现或容器卸载均清除副本。导航和保存不等待退出动画。

切换到已保留侧栏布局的另一个标签时，直接复用目标标签的登记信息，跳过退出副本的 DOM 克隆、后代遍历与逐节点滚动读取；此前这份副本会在提交后立即丢弃。同一标签内导航不采用这条捷径，因为提交前的登记仍可能属于旧页面；首次打开或目标布局未确定时继续沿用原有退出判断。查找当前侧栏时先排除隐藏或 inert 内容，再读取几何。这减少了确定无消费者的工作，未通过同数据集前后计时证明实际切换延迟改善。

首次呈现直接定位；已展开且宽度相同的两个集合不重新拉出。快速反向收展从当前插值宽度继续，减少动态效果通过组件样式关闭尺寸过渡与退出画面。紧凑模式保留原有集合／主体切换及恢复入口。

后续按截图反馈修正隐藏标签的生命周期：`WorkbenchSidebar` 按实际宽布局登记几何，不再因标签不可见撤销宽度。`useWorkspaceSidebarLayout` 合并同次布局测量与登记的中间提交，再一次交给动效容器。整屏模块加载用未确定布局表示，期间保留已有几何；详情加载不接管侧栏。恢复标签独立整行后，这些几何只影响下方内容分栏，不再使标签条先占满再退回。

素材导航通过共享适配器的 `header` 槽位，将既有“素材／词典”分段控件放到收展按钮右侧，移除重复标题行；继续使用原语言资源和键盘交互。

接入范围包括创作库、素材导航与浏览列表、词典详情集合、搜索结果、AI 活动、扩展与内容包，以及复用共享适配器的报告／历史集合。辅助面板、分屏整体折叠、大纲分支、图片共享元素和原生窗口的动效继续由各自模块负责。

类型、改动范围格式／lint 与生产构建通过；相关现有自动化回归已运行，搜索回归仍存在既有断言失败，未改写测试或搜索打开契约。没有执行 UI 手动测试，实际动画节奏、跨页面头部对齐、多 DPI 与减少动态效果的显示组合尚未验收，也没有据此声明性能提升。

2026-10-08 恢复标签独立整行后，侧栏几何、工作区快捷键、共享布局与状态连续性、搜索／拓展消费者及搜索生命周期的相关既有回归共 41 项通过；全量类型检查、改动文件格式与 lint、生产构建及差异检查通过。没有新增或修改测试，也没有操作真实应用；本轮结果不证明像素观感、极矮窗口、多 DPI 或减少动态效果组合已经验收。

## 标签切换与图文编辑器生命周期

2026-10-07 的图文标签性能排查确认：外层 `WorkspaceTabSession` 已经负责隐藏非当前标签，并设置 `aria-hidden` 和 `inert`；创作页再随标签切换进入 `Activity hidden`，会清理编辑器 effect、释放编辑会话，返回时重新构建正文及图片节点。

创作工作区现在只在同一标签离开创作视图时进入 `Activity hidden`。普通标签切换保留编辑器会话、DOM 和撤销历史；可见性与输入相关能力继续使用 `active` 和 `creationLibraryActive`。图库同样保留组件挂载，由原有 `Activity` 暂停隐藏时的 effect，从而保留浏览状态和查询缓存。数据修订仍使查询失效，缓存容量、分页、图片质量与每组最多三个挂载标签的限制不变。关闭标签或被挂载上限淘汰后，仍执行原有清理。

本轮按用户要求执行隔离的自动化 E2E，使用相同合成图片、长文与大列表，比较首次进入和重复切换的 tab 选中、内容与首图就绪、长任务、IPC、图片请求和内存。计时使用就绪后的动画帧作为呈现代理，并非屏幕像素级测量；编辑、滚动、撤销和重做另在计时后检查。详细脚本、夹具、原始结果和失败证据由测试仓维护。

## 首版历史

基线为 `58b025d8c91a303c88df34f25ce1000e19a26081`。这一版先稳定工作区外框，并区分共享集合侧栏的明确收展与直接尺寸调整，不将所有页面改成固定三栏。

| 负责位置                  | 这次改变                                      | 保持不变                                         |
| ------------------------- | --------------------------------------------- | ------------------------------------------------ |
| `AppWorkspaceGroup`       | 去掉整个标签会话的渐显                        | 会话身份、挂载上限、隐藏和 inert、保存与导航时机 |
| `WorkspaceHeader`         | 去掉侧栏头部渐显                              | 每标签独立 portal 目标，头部复用所属侧栏宽度     |
| `useWorkbenchLayout`      | 只为明确的 `setExpanded` 收展启用过渡         | 宽度与展开偏好的存储含义、拖动取消与边界规则     |
| `CollectionDetailLayout`  | 集合区域使用共享时长；内容容器裁切越界内容    | 原有焦点返回、详情选择、编辑会话与调整入口       |
| `WorkbenchNavigationPane` | 同样区分收展和直接调宽                        | 导航区与主体的原有归属、紧凑模式和入口           |
| `workbench-pane.css`      | 删除写死 200ms 的尺寸过渡，保留必要关系选择器 | 浮动入口定位与紧凑模式的相邻区域控制             |

标签选中轮廓继续使用既有 `motion-fast`，即当前 120ms 的局部透明度反馈。整页关键帧 `workspace-tab-motion.css` 已删除，不留下空文件或失效导入。

### 首版收展与直接操控

宽布局下，明确切换展开状态才启用 `transition-[width]`，复用 `duration-base` 与 `ease-standard`，当前为 180ms。CSS 从正在显示的宽度转向新目标；不引入动画队列、定时器或依赖结束事件的业务状态。

指针开始拖动、键盘调整尺寸、容器宽度变化、隐藏工作区或更换布局作用范围时清除动效资格。紧凑模式直接重排。布局仍按原规则保存偏好，装饰状态不持久化。减少动态效果时不启用这段宽度过渡。

收起仍立即隐藏并禁用内部内容，不为退出动画延长旧内容的交互生命。外层宽度变化只解释区域收拢；不复制编辑器或把旧交互内容留在透明层里。集合内容的裁切放在内部容器，不裁掉外侧分隔条。

这一版不改变主要按钮的位置，不把各标签宽度合并，也不为区域新增说明文字、标题栏、边框或主题。仍复用现有 shadcn 控件，没有新增依赖、组件专用共享变量、翻译分支或界面文案。

### 首版未覆盖的场景

只有使用上述两个共享侧栏适配器的宿主获得新的收展规则。创作页的专用多栏布局、分屏整体折叠、大纲展开与重排、图片共享元素过渡、复制或引用提示、花花和原生便签窗口都不在本批。

同层内容默认直接切换；没有新增通用页面淡入、自动插入动画或后台结果抢选机制。也没有实现新的正文滚动锚定算法，既有光标、选区与阅读位置行为仍需按实际场景验收。
