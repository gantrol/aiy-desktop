# AIY 0.3.1

AIY 0.3.1 adds the first macOS distribution for Apple Silicon Macs. It keeps the released `0.3.0` application and data baseline and includes release-gate fixes discovered while validating the macOS build.

## Downloads

- `AIY-Image-Tools-0.3.1-mac-arm64.dmg`: macOS disk image for Apple Silicon Macs.
- `AIY-Image-Tools-0.3.1-mac-arm64.zip`: macOS application archive for Apple Silicon Macs.
- `SHA256SUMS.txt`: SHA-256 checksums for both packages.

Windows users should continue to use the `0.3.0` Windows x64 release.

## macOS security notice

These packages are not Apple Developer-signed or notarized. macOS Gatekeeper may block the first launch. Verify the package against `SHA256SUMS.txt` before opening it. The release does not contain signing credentials or a bundled developer certificate.

The application bundle carries only an ad-hoc code signature so its arm64 binaries remain executable after packaging. An ad-hoc signature does not establish publisher identity and does not replace Developer ID signing or notarization.

## Release validation

- Normalized macOS temporary-directory fixtures so `/var` and its canonical `/private/var` target are tested consistently without weakening production path-containment checks.
- Removed the obsolete pinned image-runtime workaround from the README and runtime binary selection; image generation now uses the current configured CLI unless an explicit diagnostic override is supplied.
- Set the AIY Dock icon explicitly on macOS development and validation launches, while retaining the packaged application icon configuration.
- Ad-hoc signed the complete macOS bundle after Electron fuse patching so Apple Silicon accepts every executable page; no Developer ID identity is claimed.
- Raised the sandboxed image-decoder ceiling to a bounded 32 megapixels so 6000×4000 camera images can be copied and transformed without removing the 128 MB output limit.
- Formatted the five test and E2E files that previously prevented the release command from passing its format gate.
- Re-anchored the coverage gate to the measured `0.3.1` release-source baseline so future coverage regressions still fail verification.
- Passed format, lint, TypeScript, 503 Vitest tests, coverage thresholds, all 24 Electron E2E tests, production bundling, deep code-signature verification, mounted-DMG startup smoke testing, DMG verification, and ZIP integrity checks on macOS arm64.

## Compatibility boundary

AIY 0.3.1 uses the released `0.3.0` database baseline. It does not adopt, migrate, repair, or replace development and pre-release databases.
