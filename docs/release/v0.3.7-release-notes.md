# AIY 0.3.7

AIY 0.3.7 expands reusable creation workflows, adds deeper local Codex analysis, and introduces an explicit browser-companion handoff for social-post drafts.

## Highlights

- Break down a library image into structured visual observations and reusable prompt directions, then keep derived work connected to its source creation context.
- Start a blank article or social-post derivative without copying its source, or explicitly clone and convert source content while retaining navigable source and derived relationships.
- Enlarge and step through creation reference images, reorder them, and manage copy, removal, and cover actions from the shared media preview flow.
- Inspect exact Codex task, session, and turn distributions, and discover local Codex visualizations and Mermaid diagrams through constrained previews.
- Stage a selected social-post draft for the separately installed browser-companion prototype; it fills text only, and final publication still requires a user click.
- Preserve nested Markdown lists in WeChat copy, make article autosave safer, and stabilize startup and local-space transitions.

## Microsoft Store package

The Store submission package is Windows Desktop x64 with identity `Gantrol.AIY` and package version `1.3.7.0`. The upload artifact is intentionally unsigned; Microsoft handles authorization, package verification, signing, deployment, and replacement after certification.

Microsoft Store distribution and the in-app update workflow already shipped before 0.3.7. This release moves the existing background update check from about 30 seconds after the first window appears to about one second, while download and installation remain user-initiated from Settings.

The package contains only the lightweight `creation-starter` content pack. Production portrait content is not bundled and can be added only through the explicit content-pack importer.

The Chrome browser companion is separate from the Store package and currently requires developer-mode installation plus one-time per-user Native Messaging registration.

## Data compatibility

- Product data baseline: `0.3.0` (unchanged).
- Database schema revision: `5`, advanced once from revision `4` through one consolidated, forward-only migration for creation-form lineage, image breakdowns, and evaluation suites.
- The Codex usage investigator advances its separate, rebuildable cache once from schema `5` to schema `6`; it does not change local-space product data outside the revision-5 migration above.

## Privacy notes

Codex usage and visualization discovery operate on local Codex records and artifacts. Visualization previews use restricted local protocols, and optional thread-content access remains separately permissioned. Provider-backed AI features continue to send only inputs selected for a user-initiated request to the configured provider.

The Weibo handoff stages only the social-post content selected by the user for a local browser companion. AIY does not complete the final publish action.
