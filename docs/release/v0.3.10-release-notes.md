# AIY 0.3.10

AIY 0.3.10 improves article saving, library organization, local Codex history, and watermark delivery.

## Highlights

- Use a single article save queue for autosave, explicit save, retry, and history restore, with revision conflict checks and acknowledgements that preserve the active editor state.
- Reorder social-post images with dedicated drag handles and move material albums through a shared destination picker.
- Import GIF images into creation workflows alongside PNG, JPEG, WebP, and SVG.
- Browse local Codex thread messages with Markdown rendering and improved project, section, and role filtering.
- Inspect Codex quota estimates with token ranges and clearer handling of incomplete service-tier information.
- Save named watermark profiles, adjust proportional placement and size, preview a selected image, and choose a profile during browser handoff.
- Use the expanded assistant reasoning-effort options and local diagnostic records for renderer and social-post save failures.

## Compatibility

- Application version: `0.3.10`; Windows Desktop x64 Store package version: `1.3.10.0`.
- Product database baseline remains `0.3.0` and schema revision remains `5`. The assistant-run compatibility migration preserves existing records while accepting `max` and `ultra` reasoning efforts.
- The rebuildable Codex history cache advances once from revision `3` to `4`.
- English and Simplified Chinese language extensions: `0.3.10`; integrated Codex extension: `0.3.5`; history search: `0.1.1`; usage investigator: `0.1.6`; natural watermark: `0.2.0`.
- The extension-host API remains `0.3.9`. The package includes only the lightweight `creation-starter` content pack; additional content is imported explicitly.

The Store submission package is unsigned. Browser handoff stages the selected content for the companion; final publication remains a user action.
