# AIY 0.3.0

AIY 0.3.0 is the first public release and the first frozen application and data baseline. This release provides Windows 10/11 x64 packages. macOS packages are not part of this release.

## Downloads

- `AIY-Image-Tools-0.3.0-win-x64.exe`: interactive Windows installer.
- `AIY-Image-Tools-0.3.0-win-x64.zip`: unpack-and-run Windows build.
- `SHA256SUMS.txt`: SHA-256 checksums for both packages.

The initial Windows packages are not Authenticode-signed. Windows SmartScreen may therefore show an unrecognized-app warning. Verify the downloaded file against `SHA256SUMS.txt` before running it.

## Highlights

- Local-first spaces backed by SQLite and managed media storage.
- Image creation workflows with prompt versions, reference images, result comparison, annotations, retries, and imports.
- Dictionary, word-palette, gallery, album, metadata, and provenance workflows.
- Local-space creation, registration, switching, backup boundaries, and custom covers.
- Extension-based image providers and local Codex integrations.
- GPT Image 2 production-provider smoke validation completed for the release candidate.

## Compatibility boundary

AIY 0.3.0 accepts spaces created against its released `0.3.0` database baseline. Development databases and pre-release schemas are intentionally not migrated, adopted, repaired, or replaced. If a registered space's database file is missing, AIY fails closed rather than creating an empty replacement.

Optional provider extensions that remain at version `0.1.0` have not completed the same production API validation and are not part of the stable 0.3.0 provider commitment.

## Data and external services

Application data is stored locally by default. When an external image or assistant provider is used, the request data selected for that operation is sent to that provider under its own terms. Credentials are configured separately from model selection and are not bundled with the application.
