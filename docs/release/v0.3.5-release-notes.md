# AIY 0.3.5

AIY 0.3.5 adds a local Codex usage investigator and makes creation comparison and album organization easier to control.

## Highlights

- Inspect locally available Codex token history, quota observations, model shares, cache shares, and API-rate equivalents without storing prompts, replies, or absolute paths.
- Pause and resume usage investigations from SQLite checkpoints, keep derived reports separate from the source index, and export a selected report.
- Use a clearer Creator input/output workflow with improved pair comparison, image magnification, and output organization.
- Move material and creation albums within the library tree, including drag-and-drop reparenting and native file dragging to other Windows applications.
- Keep existing local-space data on the public database schema revision 3; the usage investigator stores its own cache database separately.

## Microsoft Store package

The Store submission package is Windows Desktop x64 with identity `Gantrol.AIY` and package version `1.3.5.0`. The upload artifact is intentionally unsigned; Microsoft handles authorization, package verification, signing, deployment, and replacement after certification.

The package contains only the lightweight `creation-starter` content pack. Production portrait content is not bundled and can be added only through the explicit content-pack importer.

## Privacy notes

The usage investigator reads local Codex session usage records only. It does not retain or export prompts, replies, work directories, or machine-absolute paths. Provider-backed AI features continue to send only inputs selected for a user-initiated request to the configured provider.
