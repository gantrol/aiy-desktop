# AIY 0.3.3

AIY 0.3.3 refines the local-first creation and media workflow, improves startup behavior, and prepares the first Microsoft Store package. It keeps the immutable 0.3.0 product-data baseline and advances the database schema once, from public revision 2 to revision 3.

## Highlights

- Organize imported and generated outputs in batches, with clearer prompt, provenance, version, and destination previews.
- Choose creation covers, hide unwanted outputs from presentation views, and keep those decisions across restarts.
- Browse creation and material albums with improved previews, hierarchy handling, navigation, and empty states.
- Recover images from failed AIY generation runs through Codex image discovery, or import selected Codex results as external creations.
- Import SVG artwork through the sandboxed validation and rasterization path.
- Use the expanded local Codex, Gemini, and Antigravity integration routes when their required accounts or runtimes are configured.
- Start faster by deferring non-critical workspace loading and avoiding unnecessary dense-view visual work.
- Open the privacy policy or report inappropriate AI-generated content privately from Settings.

## Microsoft Store package

The Store submission package is Windows Desktop x64 with identity `Gantrol.AIY` and package version `1.3.3.0`. The upload artifact is intentionally unsigned; Microsoft re-signs accepted MSIX packages after certification.

The Store package contains only the lightweight `creation-starter` content pack. Production portrait content is not bundled and can be added only through the explicit content-pack importer.

## Data compatibility

- Product data baseline: `0.3.0` (unchanged).
- Database schema revision: `3`.
- Released revision-1 and revision-2 spaces migrate forward in a transaction.
- Opening a registered space still fails closed when its expected database file is missing.
- Existing released SQL migrations remain immutable; 0.3.3 adds only the revision-3 creation-presentation migration files.

## Provider and privacy notes

AIY does not require an AIY cloud account. Local-space metadata and managed media remain on the user's device by default. Provider-backed AI features send only the inputs selected for a user-initiated request to the configured provider and remain subject to that provider's terms, privacy policy, regional availability, and billing.

Optional integrations that remain on `0.1.x` versions are early features and may require their own acceptance checks. No provider credentials are included in the application package.
