# AIY 0.3.6

AIY 0.3.6 unifies creation content in the library, adds recoverable content lifecycle controls, and expands reusable article and social-post workflows.

## Highlights

- Manage image creations, ideas, social-post drafts, articles, and video documents through one creation library model with stable album membership and navigation.
- Archive supported content, restore it, or move it through a 30-day recycle bin from the new Content management screen.
- Build inspiration stashes, social-post media sets, and editable articles, then generate reusable header, inline, and social-cover visuals from their content.
- Paste or drop images into video-document editing workflows and keep the imported media available for document work.
- Account for Codex Standard and Fast credit rates, including historical pricing, while keeping usage analysis separate from product data.

## Microsoft Store package

The Store submission package is Windows Desktop x64 with identity `Gantrol.AIY` and package version `1.3.6.0`. The upload artifact is intentionally unsigned; Microsoft handles authorization, package verification, signing, deployment, and replacement after certification.

The package contains only the lightweight `creation-starter` content pack. Production portrait content is not bundled and can be added only through the explicit content-pack importer.

## Data compatibility

- Product data baseline: `0.3.0` (unchanged).
- Database schema revision: `4`, advanced once from revision `3` through forward-only migrations for the unified creation-item model, creation album membership, reusable creation formats, derived visuals, and recoverable content lifecycle state.
- The Codex usage investigator advances only its separate cache schema; it does not change local-space product data outside the revision-4 migration above.

## Privacy notes

The usage investigator reads local Codex session usage records only. It does not retain or export prompts, replies, work directories, or machine-absolute paths. Provider-backed AI features continue to send only inputs selected for a user-initiated request to the configured provider.
