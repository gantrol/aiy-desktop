# AIY 0.3.4

AIY 0.3.4 makes Microsoft Store updates safer and gives library images a direct path into other Windows applications.

## Highlights

- Drag one or multiple images from the gallery or material library directly into another Windows application as native files. Dropping the same drag onto an AIY material album files the existing materials directly instead of re-importing them.
- Microsoft Store builds check for updates after startup and from Settings, while downloads begin only after the user chooses them.
- Download progress remains visible in Settings, and a downloaded update can be installed with “Restart and update”.
- Closing the window or explicitly quitting can offer to install a ready Store update. Windows shutdown and sign-out are never delayed by this prompt.
- Source and development runs do not expose an in-app updater; maintained packaged releases use Microsoft Store updates.

## Microsoft Store package

The Store submission package is Windows Desktop x64 with identity `Gantrol.AIY` and package version `1.3.4.0`. The upload artifact is intentionally unsigned; Microsoft handles authorization, package verification, signing, deployment, and replacement after certification.

The package contains only the lightweight `creation-starter` content pack. Production portrait content is not bundled and can be added only through the explicit content-pack importer.

## Data compatibility

- Product data baseline: `0.3.0` (unchanged).
- Database schema revision: `3` (unchanged from 0.3.3; no new migration is introduced by this release).
- Existing local spaces remain on the same released schema path.

No provider credentials or AIY cloud account are required. Provider-backed AI features continue to send only the inputs selected for a user-initiated request to the configured provider, subject to that provider’s terms, privacy policy, regional availability, and billing.
