# 侧栏作品拖入大纲

侧栏作品与正文形式拖到写作大纲时，在行前、行后、子项或末尾落点插入 `contentReference`。普通拖放不调用编辑位置链接解析；单个图集仍沿用导航链接。大纲条目之间的移动和复制保持原有结构操作。

`resolveReferenceDrop` 由图文与大纲共用。创作项有唯一文章形式时引用该文章；仅有一份其他受支持正文时引用该正文；其余创作项保留集合捕获。文章使用同步引用，保存已有编辑会话后重新核验来源；其他来源使用固定引用。批量引用全部准备成功后才插入，等待期间切换空间或改变目标大纲会取消插入。整篇文章不能同步嵌入自身。

落点与撤销由现有 `dropOutlineItems` 事务负责，引用身份及呈现设置继续通过正文保存链路持久化。此修改不增加数据库迁移或版本号。
