# 素材图片排列

图集详情的「内容」页和素材库创作区采用 `CollectionMasonry`，素材库中的图片及图集「图片」视图采用 `MaterialMasonry`。默认都使用等高行式瀑布流，浏览方向仍是上下滚动。

## 图集内容与创作区

- 图集「内容」页直接显示子图集、创作、素材及文档，沿用原有顺序、成员关系、默认打开行为与多形态菜单。左侧内容目录仍为紧凑列表。
- 卡片按现有封面宽高分配行内宽度；展示框比例限制在 3:4 至 2:1，图片完整显示。没有封面时显示标题与类型图标，避免只剩一块空白图片占位。
- 标题、拖动柄与多形态菜单共用固定 32 px 底栏，封面下不再分别为长标题及按钮预留多行高度。无封面卡片的标题放在卡面，底栏显示类型。
- 素材库创作区采用同样的封面行布局，显示图集名称、素材数量及操作菜单；图集移动、拖放接收与右键操作复用原有规则。紧凑行式卡片不再悬停展开覆盖相邻条目的堆叠预览。
- 「排列」可以切换等高行、等宽列并调整大小。内容卡片的标题始终可见，纯图片的「显示名称」偏好不影响内容卡片。
- 创作区和素材区分段排列，以水平分隔标题连接。各区域共用视口裁剪与滚动调度。

## 展示规则

- 默认目标行高 204 px、间隔 8 px。按素材原有顺序计算行分组，普通行两端对齐；末行左对齐，高度不超过目标值。无法合理填满的稀疏行也不放大成封面。
- 工具栏「排列」提供等高行、等宽列、120–320 px 缩略图大小，以及「显示名称」。名称默认只在悬停、键盘聚焦或无悬停设备上显示；开启后固定占用图下 28 px 单行，超出省略。
- 图片完整放入展示框，不以裁切换取齐边。展示框比例限定在 1:3 到 3:1，极端比例标明长图或宽图；详情仍通过现有素材身份打开原媒体。
- 普通素材图集卡片保留既有布局；图集详情内容与创作区按上文处理。连续文字素材独立按列排布，位于前后图片之间，不为填空改变排序。
- 选择边框覆盖在图片上，不改变卡片尺寸。切换排列、缩略图大小和名称显示不会修改选择、筛选、分页或素材关系。

## 实现边界

- `ui/justified-row-layout.ts` 只计算行的位置，`gallery/materialMasonryLayout.ts` 处理图片与文字分段及名称高度。
- `ui/masonry-surface.tsx` 共用容器测量、滚动帧调度、视口裁剪与按身份保留滚动锚点。`ShortestColumnMasonry` 保留原有计算与调用契约，其他卡片无需改用行式布局。
- 布局读取列表中已有宽高，不等待图片加载，不新增逐项 IPC、文件读取或完整关系查询；图片继续请求现有静态缩略图。没有引入图库依赖或演示图片。
- 视口外内容裁剪时保留焦点项及相邻项，让原生 Tab 可以继续访问下一张卡片。素材详情隐藏列表时保留上次有效宽度与滚动锚点，恢复显示后重新测量。
- 排列偏好保存在独立的 `aiy.material-layout.v1` 中，并在已挂载视图之间同步。缺失或非法字段使用默认值；存储不可用时保留当前会话操作。偏好不会扩展 `GRID / LIST`，创作图集的堆叠语义保持不变。
- 新文案使用现有英文与简体中文语言资源。
