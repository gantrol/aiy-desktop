# 花心屏幕放大镜

产品规则归 [AIY 屏幕放大镜](https://github.com/gantrol/aiy-docs/blob/master/design/pages/screen-magnifier.md)。这里记录桌面实现边界。

## 接入与授权

`com.aiy.screen-magnifier` 是随应用分发、默认停用的 HOST 插件，版本为 `0.1.0`。它使用插件宿主 API `^0.3.10`；这与桌面应用的 `0.5.9` 版本分开维护。manifest 由现有包加载器发现，宿主固定校验运行器 ID、贡献命令和 `screen.read:desktop-region` 权限。启用和授权沿现有插件管理流程。

插件的设置页提供“打开花花控制”，只显示花花的设置入口，不改写普通显示类型，也不启动采样。点击普通花心或右键“花心设置”，四片独立操作花瓣向有空间的一侧展开，分别为显示、计时、放大镜、外观。保留原花的位置、尺寸和内容；空间不足时在同侧紧凑排列，参数就近呈现。选择放大镜花瓣开始临时会话，花心随后提供关闭动作及调节入口。没有新增快捷键或全局鼠标手势。

放大镜不再保存为普通显示类型。停止、禁用或失败后直接呈现仍保存着的普通花心，番茄钟使用当前截止时间或暂停余量，不复制、暂停或重置计时。旧候选配置的 `mode: screen-magnifier` 已无法证明此前的显示选择，读取时明确回退为 `pomodoro`，保留计时数据；这是兼容默认值，不是恢复出的历史选择。

设置按项保存，文本与数字在回车或离开输入框时确认；失败保留输入和错误。收拢等待正在保存的操作成功，返回动效结束后缩小透明宿主窗口；开启减少动态效果时跳过动效。主动收拢将键盘焦点返回花心，点击其他软件不会夺回焦点。花花隐藏时同时收拢设置，恢复时不重开会话。

`DesktopPetalsApi.magnifier` 只接受 `start`、`stop`。主进程复用花瓣 IPC 的发送者校验，并要求发送窗口是当前空间里可见、展开且保留花心的花花；普通视图及花瓣设置视图都满足这一归属。主窗口、便签、抽屉不能代替花心启动。插件停用或撤权立即终止正在运行的会话。

## 原生运行器

首版只在 Windows x64 开启。主进程通过隐藏的系统 Windows PowerShell 5.1 编译并运行随宿主打包的固定 C# 源码，不加载插件提供的脚本、不下载依赖、不向 renderer 提供任意进程或屏幕图像接口。源码通过 stdin 传入，避免 Windows 命令行长度上限；Vite 的 raw 导入使打包后也包含同一份源码。

镜片采用 [Windows Magnification 控件](https://learn.microsoft.com/en-us/windows/win32/winauto/magapi/magapi-intro)，在独立线程消息循环中按约 33 ms 定时间隔更新鼠标附近区域。屏幕帧留在原生控件中，不经过 JS、IPC、剪贴板、文件或网络。镜片置顶、点击穿透且不激活窗口；不使用全屏放大或输入坐标转换，不申请 UIAccess 提权。

默认 2×、520 × 200 DIP，提供 1.5×／2×／3×／4× 和小／中／大三档（320 × 160、520 × 200、760 × 260 DIP）。原生线程采用每显示器 DPI，镜片按当前显示器的 DPI 计算实际尺寸。源区域始终包含真实鼠标位置，在屏幕边缘按真实可用画面裁定范围；镜片与源区域分别定位，镜片优先避让花花并保持当前方向，放不下时换侧。镜片自身加入排除列表，边框采用系统文字色。

控件不启用 [`MS_SHOWMAGNIFIEDCURSOR`](https://learn.microsoft.com/en-us/windows/win32/winauto/magapi/magapi-magnifier-styles)，避免巨大的 I 形光标覆盖阅读内容；真实鼠标仍保留在原位置。扩大横向取景范围不能使任意长行自动完整显示，也不做文字识别或段落重排。

运行中调整倍率和尺寸沿现有设置保存通道提交，主进程每次心跳只发送当前有效数值。辅助进程校验参数，原子替换一个待处理配置，在原生界面线程应用；不重启进程、不传图像，也不累积参数队列。更新失败终止会话并返回失败状态，不继续把旧画面当成新参数的结果。

## 运行归属与清理

`PetalScreenMagnifier` 持有唯一会话。花花隐藏、最小化、销毁、renderer 重载或崩溃、切到不保留花心的视图、成功改变普通显示类型、空间暂停或切换、插件权限失效、显示器移除、锁屏、睡眠或应用退出都会结束会话。展开／收拢设置，以及修改倍率、镜片、标题或计时参数不结束会话。启动期间也接受关闭；迟到的 ready 不能恢复已经结束的会话。

放大镜运行时，renderer 和主进程同时暂缓花花自动贴边收起；显式隐藏和宿主强制收起仍能终止会话。运行状态不写入布局文件，恢复花花或重新启用插件不会重启放大镜。

主进程关闭时先使会话失效，解除监听、清理超时和心跳，再终止原生进程；进程退出释放其窗口和原生资源。辅助进程另检查花花 HWND、可见／最小化／虚拟桌面隐藏状态、宿主进程、stdin 和心跳。正常退出调用 `MagUninitialize`；心跳超过 3 秒、输入通道关闭或系统会话断开也自行结束。宿主每 500 ms 发送一次有背压的心跳并重查会话归属；启动等待上限 15 秒，失败不自动重试。

## 验证边界

类型、打包和原生代码编译只验证静态与构建链路；现有花瓣及插件自动化回归不等于此新增原生会话已有专项运行覆盖。没有启动真实应用做 UI 手动检查，也没有新增或改写测试。

发布前仍需获准后验证真实 Windows 桌面的镜片可见性、文字清晰度、混合 DPI、多屏边缘、输入穿透、花心关闭、锁屏／退出和启动取消。受保护画面可能无法放大；原生 API 返回成功也不能保证每个软件的内容可读。macOS、Linux、键盘焦点跟随、冻结画面、直接点击放大控件均未实现。不根据编译或回归通过声称性能提升。
