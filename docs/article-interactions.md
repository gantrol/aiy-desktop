# 文章轻交互

## 需求边界

| 能力           | 作者需要                                                                   | 本次状态                 |
| -------------- | -------------------------------------------------------------------------- | ------------------------ |
| 折叠段落       | 在文章中选中或定位正文段落，插入可编辑的提示与展开内容；取消折叠后保留正文 | 已接入编辑器             |
| 内容保存       | 提示和正文作为结构化块保存；编辑时的展开状态不改变文章内容                 | 已接入块文档             |
| 普通导出       | Markdown、复制公众号正文和浏览器伴侣交接中，提示与正文都可读               | 已做静态展开投影         |
| 点击揭晓       | 分别编辑初始和揭晓内容，在编辑器内切换预览                                 | 已接入编辑器             |
| 点击换图       | 初始与揭晓状态各放一张图片，复用原有素材导入与保存                         | 已接入编辑器             |
| 公众号点击交互 | 在微信图文中点击展开、揭晓或换图                                           | 已生成 SVG，待微信端验证 |
| 自动动效       | 按时间播放或重复运动，并在不同目标平台提供合适输出                         | 后续独立能力             |

大纲中的折叠只影响作者浏览大纲；本文的折叠是文章正文节点。两者互不改变对方的状态。Tiptap 的 [Details 节点](https://tiptap.dev/docs/editor/extensions/nodes/details)提供编辑态的提示与内容容器，其 `persist: false` 让临时展开状态留在编辑会话中。

## 当前实现

文章工具栏的“折叠段落”把当前块包入 `details → detailsSummary + detailsContent`。插入后光标落在提示文字，作者可以直接改写；展开按钮显示内部段落。编辑态初始收起，目前没有读者初始状态设置。取消折叠会把提示与正文还原成普通块。

“点击揭晓”和“点击换图”共用 `reveal → revealInitial + revealAnswer`，区别是稳定的 `kind` 标识。两个状态各自容纳可编辑的普通正文块，包括图片。作者在编辑模式下修改两侧内容，在预览模式下切换初始与揭晓状态；“转为普通内容”会保留两侧内容。图片继续绑定原有资产，不保存显示 URL。共享块文档校验结构，保存时仍以 JSON 文档为准。

换图时分别把光标放入两个状态，使用现有“上传图片”操作加入图片；初始的文字可以改作图片说明或删除。

Markdown 是面向其他目标的静态投影：折叠提示输出为加粗段落，内容顺序展开；两状态块依次输出初始与揭晓内容。Markdown 重新导入不会恢复交互关系，编辑应使用已保存的结构化文档。

公众号复制从结构化文档生成内联 SVG，点击后一次性展开或切换状态；剪贴板纯文本仍包含完整的静态正文。浏览器伴侣先按静态正文把图片上传到公众号编辑器，取回公众号图片地址，再把 SVG 中的素材引用替换为该地址并粘贴交互正文。交接会检查 SVG 和动画标签是否仍在编辑器中；若被清洗，会尝试恢复静态正文并返回失败。伴侣版本需更新到 0.0.6。

目前 SVG 只处理正文顶层的交互块，其内容限短文本、标题和图片。含链接、列表、表格、嵌套引用等复杂内容，或图片尺寸不可用时，整篇公众号输出回退为静态正文。“点击换图”要求两个状态各有一张图片。图片顺序与文字可以混排；文字在 SVG 中会重新排版，原有行内样式不会保留。交互目前是单次点击，尚无再次收起或切回。

## 微信端验收

第三方编辑器展示了 [SVG 点击展开](https://www.135editor.com/essences/8450.html)的现有做法，但它要求同步到公众号后台，而且主要处理图片。AIY 已生成并接入导出代码；公众号后台保存、手机微信阅读和不同设备仍需实际验收：

1. 检查复制粘贴与伴侣交接后，微信后台是否保留 SVG、`animate`、图片地址和点击事件。
2. 保存草稿后，在手机微信预览文本、图片、窄屏和失败回退。
3. 按实际兼容结果调整 SVG 模板，并决定是否开放更多富文本和再次收起能力。

当前没有执行 UI 或真实公众号验证；代码输出和伴侣 DOM 检查不能证明已发布文章在手机微信里正常互动。
