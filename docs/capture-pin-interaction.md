# 截图、贴图与独立历史

截图与便签、剪贴板历史是两个宿主内置工具。目录身份同时核对宿主来源、固定 ID 与 HOST runtime；外部包声明相同名称或放进相似目录不会获得内置身份。首次拆分继承旧能力已保存的剪贴板启用与授权选择，之后独立维护。未新增数据库迁移。

## 操作与保存

- 截图按钮及方式菜单进入区域、屏幕、窗口、控件、上次选区、长截图或录制。延时采集可取消；截图与贴剪贴板图片的全局键在截图设置中独立配置，冲突保留原配置。
- 截图结果的主动作是复制；标注返回同一截图会话，贴出并编辑进入桌面。取消另存不结束选区。原生选区与窗口的坐标交接使用 DIP；历史只接收已确认区域的输出像素。
- 图片查看态直接拖动图片摆放，滚轮缩放，方向键微移。编辑态从标题区移动窗口，在图上输入文字；工具参数与查看菜单按需展开。编辑借用的窗口尺寸退出时恢复，并保留用户主动移动的位移。
- 临时与常驻、折叠与展开窗口共用花花的实际接收区域。拖入显示提示，保存成功才隐藏；撤销恢复同一内容、位置和展开状态。编辑完成返回截图的隐藏检查允许读取已保全状态，避免与当前完成操作相互等待。
- 截图历史默认记录 30 天、最多 200 条或 128 MiB。它使用独立目录与所有权，删除不会删除剪贴板快照、临时图片或正式采用结果。固定记录计入容量；无法腾出空间时报告历史保存失败，已完成复制仍有效。
- 后台历史更新不替换用户选中的条目。列表中的 Enter 复制当前项，预览、贴出和编辑分别操作。缩略图仅在进入可见区域后请求，并在宿主存储队列中生成。

## 长截图与录制

Windows 原生助手采样稳定画面并对向下滚动的重叠行做匹配，只追加新的底部条带。控制面显示缩略预览和当前高度；匹配失败或达到像素上限时保留已取得部分，停止后接回同一标注与输出流程。控制条必须放在选区外。纯色、重复图案、固定遮罩和快速滚动可能无法建立可靠匹配，不能将部分结果标为完整。

长截图以一个独立 PNG 恢复文件保存检查点，最多一项编码与写入在途，并限制刷新频率。像素副本有 2,000 万像素上限，PNG 有 24 MiB 上限；写入使用临时文件替换，失败保留上个可读检查点。编码和文件写入在原生助手工作线程进行；替换与删除两个固定恢复文件的元数据操作使用该线程上的系统同步 API，不占用 Electron 主进程。再次截图先展示恢复的部分长图；成功输出后清理恢复文件。进程异常退出最多只能恢复已写完的检查点，不能将它标为完整结果。

录制调用现有运行环境中的 FFmpeg，按配置路径、随包路径、PATH 顺序定位；未安装时显示明确错误。首个实现支持无声 MP4、15 fps、可选光标，选区最多 8,294,400 像素，最长 10 分钟，文件限制设为 120 MiB 留出封装余量。控制面提供停止、预览、另存与丢弃，不能移动进采集区域；预览由系统视频程序打开。暂停、系统声和麦克风未提供占位控件。

仅保留一个未导出的分片 MP4。锁屏或取消宿主会话时请求编码器结束，失败时终止子进程并保留文件；下一次录制先处理恢复文件，避免覆盖。恢复文件必须由用户预览确认，文件存在不能证明视频完整。另存失败保留恢复文件，明确丢弃才删除。

录制依据：[FFmpeg gdigrab](https://www.ffmpeg.org/ffmpeg-devices.html#gdigrab)、[输出时长与大小限制](https://ffmpeg.org/ffmpeg.html)、[分片 MP4](https://ffmpeg.org/ffmpeg-formats.html#mov_002c-mp4_002c-ismv)。文件大小限制可能略有超出，分片容器也不保证所有播放器具有相同的兼容性。

## 核对边界

修改使用现有自动化测试、TypeScript、ESLint、生产构建及 C# 编译检查；没有新增测试或改写旧断言，没有启动原生采集入口进行界面验收。旧单元用例仍断言展开便签不能收回，和本轮确认的行为冲突，保留其失败供后续按授权更新。

真实多屏 DPI、原生焦点、滚动匹配、长截图检查点恢复、录制权限与播放器兼容性需要运行验收；静态检查不构成这些交互的通过证据。截图插入准确正文目标和非临时图片的原位置编辑也不能由临时贴图路径推定完成。跨设备剪贴板按要求搁置。
