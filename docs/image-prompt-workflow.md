# 图文封面与逐图 Prompt

图文的封面创作默认使用通用封面要求和 3:4 画幅。画幅菜单可选择方形、横图、宽屏或公众号 2.35:1；交给 ChatGPT 时会附带当前画幅，公众号画幅还会带上方形裁切要求。

来源中的封面和正文图片会按顺序加入参考图，沿用创作输入最多默认选取八张参考图的规则。在来源缩略图上可以调整选择。交给 ChatGPT 时还会收集 Prompt 编辑区的内嵌图片，并去重；单次交接最多携带二十张图片。

## 一次生成不同的图片

1. 在主编辑区写共用内容、背景和风格，选择参考图片。
2. 打开“逐图 Prompt”，为每张图片填写独立要求。可增删，最多十张；单张要求可以指定自己的比例、文字和参考图。
3. 保存清单。它会作为可编辑内容保存在同一份 Prompt 文档中，随草稿、版本和输入恢复一起保存；再次打开“逐图 Prompt”可以继续修改。
4. 点击“让 ChatGPT 做”，由浏览器伴侣携带 Prompt 和图片。交接指令要求分别输出图片，不拼成一张网格。
5. 在各张生成图片上使用“回到 AIY”。返回的图片分别保留在本次交接绑定的创作和 Prompt 版本中，再选择要用作封面的图片。

修改 Prompt 后再次交接会保存对应的不可变版本。回传图片保留该次交接的完整 Prompt，不会随之后的编辑改变；逐张回传也不会自动替换已经选定的创作封面。

单次交接文字上限为 10,000 字符，包含画幅要求。超出限制时会提示缩短内容，不会静默丢弃逐图要求。应用支持最多十条逐图要求，实际生成结果以 ChatGPT 返回为准。
