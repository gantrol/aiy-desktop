# 桌面花瓣与 AI贴贴Y

从 AIY 图标菜单的“AIY 花花”子菜单选择“显示主花”，或在已保存随记的输入栏选择“贴到桌面”。“我的花瓣”找回已有桌面实例。

## 操作

- 拖动花心移动主花。点击外瓣打开空白草稿，也可以将外瓣向花体外拖出，出现心形预览后松手打开便利贴；新窗口就绪后原瓣补长。首次保存非空文字或添加图片时创建灵感；没有图片的空白或纯空格草稿不会入库。
- 可以同时放多片花瓣。点击已放出的花瓣展开，拖动它调整位置；拖回主花可见轮廓内松手隐藏，透明留白不触发隐藏，也不删除正文。Esc 归位，失焦或丢失鼠标捕获后继续跟踪，实际松手才结算。
- 顶栏只保留“更多”和“收起”。五种颜色、八个图标合并到“更多 → 外观”；多个图层时显示“移到图层”。点击或按 Enter / Space 在菜单内部展开选项，左右方向键展开、收起分组，Esc 关闭菜单。展开纸面与收起花瓣共用所选外观。
- “在 AIY 中打开”“再放一份”“隐藏这片花瓣”“从桌面移除”归入“更多”。“再放一份”共用正文，每个摆放实例可以选择不同外观；移除只取消桌面实例，保留原内容。
- 主花下方不再常驻按钮。右键主花可打开“我的花瓣”、设置花心、打开 AIY 或隐藏主花。“隐藏全部花瓣”先保存并取消全部实例的显示选择，保留主花；“显示全部花瓣”解除图层遮蔽并恢复桌面实例，也可从“我的花瓣”逐片勾选。隐藏状态随本机布局保存，不删除内容。
- AIY 菜单提供“显示主花”“我的花瓣”“隐藏全部花瓣”“花心设置”。“我的花瓣”工具栏放添加、花花图集和更多；更多中管理图层、显示全部和隐藏全部。“重新加载花瓣”位于应用设置的“维护”页。隐藏和重新加载先保存文字。

### 图集贴贴

创作图集和素材图集可以从详情页的“贴到桌面”入口加入贴贴，也可在“我的花瓣”的内容选择器中查找；创作列表的图集右键和更多菜单提供同一操作。图集贴贴只保存来源身份，展开后显示现有封面，空图集显示图集图标，点击打开原图集。它们支持外观、图层和显隐；重命名、成员与封面变化会刷新，归档隐藏并保留关联，删除移除贴贴。旧版三类来源的贴贴表在原 revision 6 内事务升级，保留原有贴贴身份、外观和图层。

### 0.5.0 的摆放与恢复

0.5.0 不提供抽屉和收纳操作。点击主花外瓣、新建便签、从主花拖出和“贴到桌面”都产生桌面实例；便签收起后回到自己的心形。

此前已收进抽屉的实例在加载布局时转为隐藏的桌面花瓣，内容、身份、图层和位置保留，可从“我的花瓣”逐片勾选显示。首次恢复不会将这些实例全部弹出。

独立花瓣拖回主花或花苞并成功回收后，花心和主花右键菜单在 10 秒内提供“撤销上次回收”，恢复最近一片花瓣及其拖动前的位置。便签缩成花瓣不会生成撤销；重新显示该花瓣、移除或切换资料库后不再使用旧撤销，隐藏图层中的花瓣也不会被撤销操作唤回。正文编辑历史不受影响。

单片便签和内容贴贴的菜单提供“暂不置顶 / 恢复置顶”，选择只在本次运行有效，重启后恢复置顶。Windows 的 Win+D 显示桌面不改变置顶标志；辅助进程识别该快捷键后，在 Shell 过渡结束时恢复仍应显示的置顶窗口，不抢焦点，不唤回手动隐藏的实例、隐藏图层或暂不置顶窗口。

### 文件附件

便签和主窗口随记支持选择、拖入及粘贴文件。纯图片沿用正文图片导入；混合文件批次保存为附件。PDF 和其他文件可点击文件名交给系统打开，音频、视频提供按需播放器及拖动进度；内嵌播放能力取决于 Electron 支持的媒体编码，文件名始终保留系统打开入口。脚本和可执行文件只在文件夹中定位。

每篇最多 100 个附件，单个文件最多 64 MiB，一批最多 256 MiB。批次按文件串行读取和保存，显示完成数量，取消停止后续文件；已完成的附件保留。附件元数据随正文修订保存，内容按哈希保存在资料库的独立对象目录；移除附件不删除历史修订引用的文件。尚未提供该目录的历史对象回收。分享同一便签的桌面实例使用同一组附件，执行任务时附上本次选中便签的附件名称和本地路径。

### 辨认花瓣

桌面花瓣下方使用短标题组件。有标题沿用原题；无标题取正文首个非空内容行，省略 Markdown 标记；空白草稿显示“新便签”，仅含参考图片时显示“图片”。长标题单行截断，不写回正文或额外创建名称字段。

Windows 下连续轻按两次 Ctrl 切换心形花瓣的标题，焦点在其他应用中也生效；Ctrl+C 等组合键和长按不触发。状态保存在本机布局中，切换时只广播显示状态，不重新读取正文，不改变心形坐标。主花右键菜单也提供标题开关。输入辅助进程随应用退出，只输出切换信号与活动拖动的松手编号，不传出其他按键。

悬停约 400ms 或键盘聚焦显示完整标题及正文片段，有参考图片或图片来源时显示图片预览。预览按需读取当前一片，不批量加载正文、不创建编辑器。临时窗口空间与右键菜单分别管理，退出预览后恢复原位置；点击、拖动、滚动、失焦或 Esc 关闭预览。

### 内容与图层

右键主花选择“贴内容”，可搜索并贴出文章、社交帖或图片；列表工具栏也有同一入口。文章和社交帖读取当前已保存正文的预览，在原编辑器继续修改。图片复用已有资源，在系统图片查看器打开；不把资源 ID 当作素材 ID 跳转。

文章、社交帖的编辑栏也提供“贴到桌面”，先保存当前内容再贴出；图片右键菜单提供同一入口。贴出的是来源引用，不生成另一份正文。

“图层”管理分组名称及显示状态。有两个及以上图层时，花周围显示对应的小点；单层时不显示。点击选中并唤出该层，再次点击当前可见层隐藏它。新摘取和新贴出的内容进入当前层；展开后可以换层。删除图层把其中的贴贴移到默认层，不删除贴贴或原文。隐藏图层先保存编辑内容，失败时保留窗口。

内容贴贴只保存来源身份与外观，原文更新后读取新版，不复制正文。移除内容贴贴不删除来源；来源删除后清理关联，归档保留关联。它与“从文章生成另一篇稿件”不同，生成的独立作品仍保留人工修改。

### 尺寸、摘花与贴边

主花默认 144px，可在花心设置中调整为 128–184px；收起的花瓣窗口为 112×112px，为心形下方的短标题留出空间。独立透明窗口使用统一文档根样式，外围不滚动，长正文和列表在各自内部滚动。

展开的便签与内容贴贴可拖动右下角调整大小，也可聚焦该控件后按方向键微调。尺寸范围为 280–640px × 300–800px，并受当前屏幕工作区限制；每个桌面实例记住展开尺寸，收起不会覆盖它。图集选择列表限制在窗口可用空间内，长名称截断，列表内部滚动。

摘花从 SVG 花瓣实际轮廓开始。向外拖动时临时扩展到所有屏幕工作区的包围范围，保持花心的屏幕坐标，预览跟随指针，可直接跨屏摘取。拖动中的玫瑰瓣渐变为心形预览；松手后保留预览，等待便利贴内容和原生绘制就绪再显示、补长原瓣和恢复主花窗口。首次绘制等待期间临时关闭该窗口的后台节流，显示后恢复；前台有其他应用时也能完成隐藏窗口的绘制。主动摘出的展开便签沿用展开动画并激活到前台；启动恢复和收起花瓣的交接仍不抢焦点。初次绘制等待设有十秒兜底，失败或取消不会补长或持久化空便签；临时范围不写成本机位置。落点按松手指针所在屏幕的工作区校正，避免落入错位屏幕之间的空隙；便利贴展开时按该屏幕可用空间校正位置。

拖花心移动主花，以花体尺寸而不是透明窗口留白限制位置、判断贴边。靠近屏幕工作区四边后，玫瑰逐层收束成花苞，保持俯视朝向；悬停约 200ms 或点击展开，移出约 600ms 后收回。收束约 320ms，展开约 420ms，中途重新移入会从当前形态展开。收束完成后才缩小原生窗口，展开前先扩窗；减少动态效果时直接切换稳定形态。花苞最长边为 56 DIP，原生窗口由真实轮廓加操作余量计算。按下指针会取消待执行的收起，开始拖动主花时立即解除贴边。贴边位置随本机布局保存；明确从菜单唤出主花会展开。

展开花采用八片宽肩外瓣、五片包合内瓣和完整的深色圆形花心，使用纯 SVG 三次贝塞尔路径、瓣面渐变和独立卷边。外瓣分成四片较长护瓣与四片错位短瓣，内圈按 72° 排布并轻微调整长宽，形成由外向内收紧的玫瑰轮廓。瓣缘、杯形暗部与统一的左上方受光表达深浅；卷边裁切在所属瓣面内。花苞使用与展开态逐点对应的包合轮廓，旋转与局部形变分开计算，收束时由三片外包面覆盖先收拢的花瓣，减少交错瓣缘。轮廓与材质共用局部变换，主花和贴边窗口共用收束端态与包围框。只有外圈可见花瓣响应摘取；内瓣遮挡后方操作，不触发摘取或花心撤回。主花和花苞的回收命中使用同一绘制几何。独立花瓣沿用原版心形 SVG、66×82 DIP 绘制槽、图标、任务信号和配色，下方保留短标题。摘取预览使用相同心形组件。时间、计时与额度显示在深色花心区域，花心操作范围随可见圆形轮廓裁切；撤销操作保持原优先级。

花心指针操作由可见 SVG 路径处理，文字按钮保留键盘操作。摘取预览以实际按下位置跟随指针，松手位置按心形绘制槽的中心计算；空标题仍保留同样的标题行高度。扩大临时窗口前固定花心屏幕坐标，窗口 resize 与新快照之间继续使用该坐标，避免主花暂时跳到大窗口中央。主花直接定位在窗口视口上；桌面画布与文档根使用不可滚动的裁切，文档根禁用浏览器滚动锚定，避免外移的 SVG 花瓣触发隐式滚动、把整朵花往反方向带走。便签正文与列表仍使用各自内部的滚动区域。

右键主花使用同款浅桃色菜单，内容、计时与窗口操作分组排列；支持 Esc 和键盘菜单键。菜单显示前临时留出窗口空间，关闭后恢复，选择菜单动作前先完成窗口恢复。菜单和摘花各自持有临时空间，互不提前结束对方的操作。

拖至边缘松手后先保留完整花朵，鼠标离开后再延迟收起；拖动、摘花交接和菜单期间不收起。展开位置独立保存，不从花苞反推位置，避免靠近角落反复展开时发生漂移。跨屏拖动以指针所在屏幕校正位置。

临时窗口扩展导致的失焦、捕获丢失不提交或取消摘取；继续跟踪到松手。Windows 的鼠标摘取同时通过辅助进程读取实际松手，渲染器丢失捕获或收到指针取消时仍可完成交接；每次手势独立编号，原生与页面松手只提交一次，退出或超过 60 秒停止监听。辅助进程未就绪时沿用页面事件。达到摘取距离后心形保持可见，松手点在主花可见轮廓内才归位，花瓣间透明空隙和窗口留白不回收。未摘出的短拖、Esc 和没有原生后备的指针取消会归位。独立花瓣拖回主花时使用同一轮廓判定；主花贴边收起后只回收落在花苞可见轮廓内的花瓣。

## 图片与 Codex 任务

粘贴独占段落的网页或 X 链接时先保留链接，就近提供“保留链接 / 转为链接卡片”，支持每行一条的多链接粘贴。链接所在块的菜单可转为卡片，卡片可“转为链接”，转换支持撤销。按回车或导入 Markdown 不会自动转卡片；已保存的卡片保持原有形式。

粘贴 Codex 任务链接时先保留链接，由启用的 Codex 扩展就近提供“保留链接 / 转为卡片 / 关联为下属任务”。空段落支持一次粘贴多条链接，每行一条；继续输入或按 Escape 可收起操作，按向下键可进入选项。链接所在块的菜单可再次选择展示方式。未启用扩展时不出现这些 Codex 操作，也不会自动将任务链接变成卡片。

“下属任务”表示已有 Codex 任务与当前花瓣的本地关联，可关联多个任务。关系随花瓣的结构化文档保存，支持撤销、移除块及转回普通卡片；同一花瓣的其他桌面视图会同步关系变化。关联不启动任务、不修改 Codex 内部任务层级，也不将外部任务视为 AIY 发起的执行回执。通用编辑器只提供链接贡献接口；协议识别、任务卡片和关系语义由 Codex 扩展负责。扩展使用现有启用状态快照，不因粘贴或展示关系新增 Codex 请求。

便签底部“＋”支持从图库选择及导入图片，也接受图片拖入、粘贴。引用复用现有图片资产，不覆盖原图；首次添加图片也可保存空文字便签。最多 8 张参考图，单张 25 MiB、单批 100 MiB；文件导入接受 PNG、JPEG、WebP、GIF。只读结构化随记在原编辑器修改。

便签的主要操作是记字、保存、图片和摆放；Codex 是可选的任务执行应用。底部应用名称默认收起，点击后显示操作；同一便签共用一份状态订阅，收起后仍可显示任务灯，后台任务继续执行。新便签继承当前资料库最后选择的便签图集，重启后保留；图集被删除或归档时回到默认图集。先选择 Codex 已保存的本地项目或明确选择“不关联项目”，再点击“执行新任务”。项目列表显示名称与工作目录；运行前再次校验目录，失效时保留输入并报错。选择项目不会创建任务、分支或 worktree。

每次执行以已保存的便签为输入，新建一个独立 Codex 任务，不自动续接旧任务。正文和附件仅在本次执行内存中传递；本地保留内容哈希、正文修订 ID、模型选择、项目 ID、工作目录、Codex 任务与轮次关联、状态及图片收集回执。同一随记的多个桌面实例共用最新执行状态；运行中可停止，需要后续处理时打开原 Codex 任务。未关联项目时使用当前资料库内的独立执行目录。

底栏用一条分隔线和可收起的 Codex 工具栏区分便签本体与任务操作。展开后，应用名、状态链接、设置图标和“执行新任务／停止”紧邻排列，窄窗口自动换行。状态以小圆点提示，执行按钮使用当前便签的墨色突出显示。设置图标的“项目与模型”弹层集中放置此便签的项目、模型、思考强度和插件入口；未指定项目时显示“选择项目”。项目与模型随便签保存；尚未指定项目且没有旧任务的便签沿用当前资料库最后选择的项目，明确选择“不关联项目”也会记住，重启后保留。已有便签和旧任务优先使用自己的项目。同一项目的多个工作目录归为一组，项目 ID 与规范化目录相同的条目去重，不把同名但目录不同的目标合并；刷新按钮绕过项目缓存。

模型和可选强度从当前 Codex 连接读取，不硬编码模型名称；未选择时沿用 Codex 默认，选择模型后可单独选择该模型支持的强度。每次执行都使用当前设置，不继承旧任务的覆盖值。

任务发送时保留图片附件，并把正文中资料库相对图片链接转换为可读取的本地文件链接，不修改便签或原图。空回答、超时、停止和收集失败分别记录，便签状态栏可打开失败详情；再次执行由用户发起，不自动重放可能已经产生副作用的任务。旧任务中未记录的原因不会被猜测补写。

完成后的图片进入所选的“花花图集”，便签状态栏可打开原任务及其结果图集。便签不内嵌回复正文、附件或结果缩略图；文字从统一的任务历史或原 Codex 任务查看。运行中链接明确显示“停止并在 Codex 中打开”，先停止 AIY 的执行、等待专用连接退出，再交给 Codex；不会悄悄中断仅展开便签的操作。模型执行结束后立即关闭专用连接，再收集图片，避免本地入库继续占用会话。

图片只有取得入库回执并完成图集关联后才算收集完成；中断后保留已有输出描述及回执，可重试收集，避免再次生成或重复导入。自动收集当前接受 PNG，沿用入库协议的单张 25 MiB、最大边长 4096 限制。执行回执不保存提示词或文字回答；旧版重复保存的正文在打开资料库时清理，原便签修订与 Codex 任务历史保留。

Codex 插件页面按“任务历史 / 素材 / 用量 / 设置”分组，任务历史是默认入口，保留原有的项目导航、搜索和只读任务详情。花瓣发起的任务纳入同一历史，不另设“花瓣任务”列表或聊天记录，也不提供对话输入框。新任务标记为用户发起；旧任务通过当前资料库的执行回执补充任务 ID 来源标记，历史缓存只保存该关联，正文仍从 Codex 读取。用量调查（“Codex今天努力了吗？”）负责统计；花心仅消费额度状态。素材页合并图片与可视化发现。设置中的“生成图片保存到”只决定后续任务生成图片的收集图集，与便签所属图集独立。“花心额度来源”单独归入花心显示设置。已有任务保留执行时的项目与图集。停用插件后普通便签、图片和图集仍可用，已有任务链接保留；运行任务会中断，不伪装成成功。

项目 ID 保存在 AIY 的关联中，执行通过 Codex App Server 指定工作目录。当前已核对的协议没有项目归属写入接口，因此不能承诺 Codex 桌面侧自动按该项目分组；不会直接修改其内部数据库。

Windows 默认优先使用 Codex Desktop 管理目录中可用的最新 Codex 可执行文件；没有时才使用 PATH 中的 `codex`。显式 `CODEX_BINARY` 配置仍优先。AIY 用该程序启动独立 stdio app-server，模型列表、连接检查和任务执行采用同一解析规则。版本过旧时显示升级提示，并保留失败详情；更新 Codex 后重启 AIY。此接入复用 Desktop 管理的程序，不连接桌面端正在运行的私有会话通道。详见[内容应用接口](extensions/content-applications.md#codex-runtime)。

## 花心设置

通过 AIY 菜单的“AIY 花花 → 花心设置”或右键主花进入。默认仅显示花朵，可改为地区时间、番茄钟或 Codex 剩余额度。

- 时间使用地区时区，例如 `Asia/Shanghai`、`America/Los_Angeles`，随地区规则处理夏令时。
- 番茄钟默认专注 25 分钟、休息 5 分钟，可以暂停后调整。点击花心开始或暂停，设置中可重置或进入下一段。主进程按截止时间完成计时，隐藏窗口不影响到点处理；重启后过期的计时只完成一次。到点显示“完成”，可启用系统通知，手动开始下一段。尚无长休息轮次和历史统计。
- Codex 额度由 Codex 插件提供，复用现有连接及额度读取权限，显示实际剩余百分比；无权限或无数据时显示不可用。额度类别在插件设置中选择，可见时每分钟刷新。

花心设置和计时状态保存在本机布局文件，与随记正文分开。

## 界面语言

主花、便利贴、花心设置、右键菜单及错误提示跟随 AIY 主窗口的界面语言。切换语言只更新显示文案，保留正在编辑的正文、所选颜色和图标。花瓣没有单独的语言设置；未收到语言资源时使用英文基准。

## 保存与恢复

正文、修订、颜色、图标、编辑检查点、内容引用与图层成员关系存入所属资料库的 `library.sqlite3`。坐标、贴边方向、是否显示、展开状态、当前层、隐藏层以及抽屉归属、顺序、浏览锚点和屏幕配置位置存于本机应用设置的 `ui-state/desktop-petals.v1.json`，不在布局文件中复制正文。换机器后可从列表找回已有实例。

新摘下的空白花瓣仅有临时视图，颜色和图标也先在内存中保存。首次非空文字保存或成功添加图片时，同时创建灵感、桌面实例和第一条修订；初次保存前的文字与检查点仍是进程内草稿。关闭没有文字、图片的空白花瓣会移除临时位置，不留下空灵感。已有随记清空正文属于编辑，不自动删除它的身份和历史。

停止输入后自动保存。中文输入法组字期间暂缓正式提交。保存冲突或失败时保留文字并显示状态；“核对”可比较已保存内容，明确采用自己的文字或已保存版本。收到另一入口的更新时，有未保存输入的窗口保留自己的草稿。

切换资料库、正常退出和安装更新之前先保存全部便利贴。保存未完成会阻止继续关闭；切库成功后恢复目标资料库的桌面摆放。复杂的词条、配方或非等价提示词节点只读展示，通过“在 AIY 中打开”继续编辑。

来源灵感删除后，关联桌面实例及位置一并移除；归档时关闭视图并保留实例关联。花瓣模块订阅资料库内容失效通知，并在事务结束后核对实际状态，因此删除回滚不会误移除花瓣。删除入口无需调用花瓣窗口。永久删除的外键级联同样会清除实例。

数据校验或启动失败的窗口由预加载层响应退出，不再等待从未加载成功的编辑器保存。正常编辑器的真实保存失败仍保留文字；错误提示提供重试和隐藏入口。新增花心字段兼容旧快照，避免旧主进程缺失字段导致枚举校验失败。主进程更新需要完整重启 AIY。

随记正文复用 `inspiration_stashes`。外观和位置的修改不增加正文修订；同一随记的修订按递增序号排序。主窗口和桌面便签共用保存基线检查。内容引用使用 `desktop_content_pins`，图层及成员使用 `desktop_petal_layers`、`desktop_petal_memberships`。资料库通过现有迁移入口一次推进 schema revision 6；同为 revision 6 的旧开发库缺少整组图层表时补齐，部分存在的异常结构明确拒绝，不猜测修复。

英文花瓣基准位于 `src/shared/i18n/desktop-petals.ts`，由现有 `src/renderer/i18n/locales/en.ts` 引入；中文在语言扩展的 `messages.json` 中维护同名子树。主窗口传递已解析资源，主进程校验后用于窗口标题、通知并广播给花瓣；只有主窗口可以修改这份语言视图。花瓣组件和右键菜单使用项目统一 `useI18n().messages`，无需主窗口通用 API。业务配置保存稳定标识；错误与额度状态在显示时翻译。

花瓣窗口使用独立入口，不加载完整工作台，也没有主窗口的通用 API。窗口保持接收鼠标输入，便签标题栏使用原生拖动区；花心点击/拖动、单瓣点开/拖动以及摘取使用各自的指针事件。只在用户移动完成时判断贴边，程序调整窗口尺寸不触发贴边。不会在鼠标经过空白区域时将整窗切为鼠标穿透；重新显示窗口也会先恢复鼠标输入。布局文件异步读取、合并写入并原子替换；隐藏窗口不因其他便签每次保存而重新读取正文。

交互控件复用 `components/ui` 的 Button、Input、Textarea、Select、Popover、Checkbox 等组件。`PetalControls` 汇总面板及图标按钮；图层选择和外观选择同时供两类贴贴复用。颜色与图标契约集中在 `shared/contracts/petal-appearance.ts`，显示映射集中在对应 renderer 模块。样式统一从 `styles/index.css` 进入；透明文档和滚动根规则归 `base.css`，局部布局使用 Tailwind，动画及 vendor 规则留在组件旁。没有向共享 tokens 添加组件变量。

便签、收起花瓣与抽屉的选项菜单复用 `PetalMenuContent` 和 `PetalMenuSection`：同一面板内折叠展开，宽度受原生窗口视口限制，高度不足时内部滚动，颜色与图标按可用宽度排列。默认便签窗口只有 328px，主菜单与横向子菜单各 200px 时无法并排；Portal、z-index 和左右翻转都不能突破 Electron 窗口边界。后续增加外观、图层或屏幕选择时继续复用内联分组；评审需核对最小 280 × 300 窗口、屏幕边缘、缩放、长名称和多选项时的宽高约束。UI 验收须由用户明确要求后执行。

增加来源类型时，同时维护来源契约、SQL 预览适配和打开来源动作；保存来源稳定身份，不保存复制的正文。来源列表每页最多 30 条，文字预览最多 4,000 字符；每库最多 200 个内容贴贴、8 个图层。不要让内容删除仓储回调窗口，也不要把原生窗口对象传进数据库层。

## 当前范围

收起的随记与内容贴贴复用 `CollapsedPetal`，按下不绘制矩形按钮背景，拖起仅轻微倾斜、放大。拖动超过 6px 才开启原生移动；移动 IPC 保持最多一个在途，只保留最新坐标，最后一次移动完成后再结束手势。窗口级松手、失焦、捕获丢失及重新进入时的按键状态都用于释放手势，旧请求失败不会取消下一次拖动。花瓣菜单使用非模态模式，避免在切换视图或隐藏时留下整页鼠标锁定。收起动画提供一次性的 240ms 完成兜底，不依赖动画结束事件；减少动态效果设置仍生效。本次修复仅做类型、Lint 与构建检查，未触发 UI 验收，实际卡住原因仍需运行观察确认。

本实现包含 SVG 花瓣、AI贴贴Y、文章、短帖、图片及两类图集的内容引用、图层、贴边、花瓣抽屉、屏幕变化后的摆放恢复、外观选择、本地保存、可配置花心、纸面尺寸调整，以及 Codex 项目选择、任务执行与结果收集。用户 SVG 图标导入留待后续。打开和拖动窗口时会校正到可见工作区。收起花瓣采用固定显示尺寸，窗口切换先解除旧尺寸约束，避免纸面尺寸撑大花瓣。抽屉本次只做静态检查，未执行 UI 手动验收。

Codex 内容偏好和执行回执追加在同一 schema revision 6 内，历史中的用户发起任务 ID 关联归入原有缓存 revision 4；未递增产品或插件版本。任务使用独立事件通知；正文保存和拖动不会反复读取 Codex 状态。便签只取最新执行回执，历史浏览统一读取 Codex 的历史索引。

共享同一随记与生成下游作品是不同的操作：桌面实例共用正文，下游文章、图片等作品不会因为随记修改而自动重写。
