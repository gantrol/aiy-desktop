# 空白图文改用大纲

在图文编辑器头部，正文仍为初始空段落时显示“改用大纲”。直接在同一篇作品上建立首个大纲条目，不新建文章、创作项或标签页。原图集、标题、作者、参考材料、封面及附件的持久化数据保留；继续使用既有大纲工作面。大纲当前的材料呈现边界没有在本批扩大。

本批只处理空白图文起步纠错，不包含已有正文提纲化、大纲展开为文章、反向空大纲转换或 PPT 联动。仅初始空段落符合条件；已有文字（包括空格）、标题、列表、图片、引用和刻意空行均拒绝。不是通过截取文本或重置文档隐藏损失。

## 保存与并发

前端先保存并重新核对实时草稿。主进程在事务中核对 spaceId、articleId、expectedRevisionId 和空白条件，复用 saveSystemRevision 保存。原空段落的身份及属性保留，只加入必要的大纲列表和条目结构。既有修订不修改，用户仍能通过版本历史恢复。

未知提交结果保留请求供核对；已是大纲时返回当前作品，不再改写或建立第二篇。版本变化或新内容使操作失效时拒绝。前端共享同一编辑会话的提交锁；请求期间输入的新内容由原保存会话保留，不能因异步响应切走或覆盖。工作面依据当前会话草稿的编辑方式，而非迟到的父级文章投影。

## 接口与界面

新增 article-outline-start 命令，仍走 content-library:command。没有新增存储表、迁移、应用版本、插件版本、编辑器或独立流程系统。按钮及错误使用现有 i18n，英中资源同步；正文不增加操作说明。
