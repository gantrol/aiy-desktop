# Project Commands

Extensions → Features → AIY Built-in Tools → Project Commands uses the existing `com.aiy.maintenance-guide` identity and project store. Handbooks, notes, links and import/export remain available. Enable the optional project configuration permission before choosing a local folder. Scans only produce candidates; Save candidates adopts the reviewed list. Manual commands work without folder access.

The scanner reads known configurations inside the selected real directory, skipping symlinks, dependencies, generated directories and forbidden paths. Limits are 512 directories, depth 8, 8,192 entries, 128 configuration files, 512 KiB per file, 8 MiB total and 256 detected commands. Reads are asynchronous and serial with cancellation and permission checks. No scripts, package managers, manifests, build tools or subprocesses are executed to discover commands. Environment availability is not checked.

Package scripts use npm, pnpm, Yarn or Bun only when the nearest package manager declaration or lockfile identifies one. Cargo distinguishes binary targets, tests, release builds and publishing. SwiftPM literal executable products remain suggestions because its manifest is executable code. Xcode shared schemes, .NET projects, MSBuild projects/solutions and CMake presets supply separate build/run/publish/configure candidates. Dynamic conditions, inherited configurations, debugger parameters and incomplete publishing inputs remain unresolved. See the [Cargo target rules](https://doc.rust-lang.org/cargo/reference/cargo-targets.html), [CMake preset reference](https://cmake.org/cmake/help/latest/manual/cmake-presets.7.html) and [.NET publish reference](https://learn.microsoft.com/en-us/dotnet/core/tools/dotnet-publish).

Stable identifiers distinguish sources, targets and operations. Rescanning preserves manual edits and marks changed/missing sources. Import clears directory authorization. Revision checks prevent a late scan or stale editor from silently overwriting a newer save. Saving is bounded by the existing 4 MiB project store. AI completion, command execution, IDE debugging and external ChatGPT integration are not wired by this change.

Existing extension regressions cover surrounding loading, permissions and UI contracts. There is currently no direct automated suite for the new scanner/adoption path; no new tests or manual UI checks were added.
