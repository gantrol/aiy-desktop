# Security Policy

## Supported versions

Security fixes are provided for the latest published AIY release. Pre-release builds and development databases are not supported release baselines.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or include credentials, personal data, database contents, or exploit details in a public discussion.

Use GitHub's private vulnerability reporting for [`gantrol/aiy-desktop`](https://github.com/gantrol/aiy-desktop/security/advisories/new). Include the affected version, operating system, reproduction steps, impact, and the smallest safe proof of concept.

The maintainer will acknowledge a complete report as soon as practical, coordinate any additional validation privately, and publish remediation information after a fix is available.
