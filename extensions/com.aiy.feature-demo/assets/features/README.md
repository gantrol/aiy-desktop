# Fixed feature demo samples

- `vectors.json` contains an original AIY illustrated article, demonstration transcript and six key frames about vector routes. `vector-owned-*.svg` are original coordinate diagrams created for this project. The synthetic two-minute timeline demonstrates the existing article, transcript and key-frame views without requiring a source video. It is not a recording or a transcript of a third-party lesson. These text and diagram assets follow the repository license.
- `portraits.json` and `portrait-*.png` contain three existing Codex-generated fashion studio portraits, in generation order. Image bytes, content hashes, and timestamps are preserved.

These samples are packaged with the feature demo. Playback and export use the same files, independently of the current library and Codex discovery results. Demo identifiers replace library and task identifiers; generation receipts and local filesystem paths are omitted. The shared chapter and sample labels use the application's i18n resources.
